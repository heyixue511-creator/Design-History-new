## 二、本章在全书中的位置

### 2.1 承接导论

导论解释设计史的对象、材料和方法，却尚未解释近代生产关系如何重新组织形式判断、制作知识和决定权限。第一章从认识论转向历史机制。

### 2.2 本章问题

> 在约1750—1914年的工业化过程中，形式判断、制作知识和决定权限如何被重新分配、外化、传递和命名？

这一问题取代“工业革命是否发明设计”作为直接研究中心。后一个问题可保留为教学设问，但不得预设专业设计必然出现。

### 2.3 暂定中心论点

> 工业化并未发明一种此前不存在的构思活动，而是在若干行业中，通过劳动分工、图样与模型、企业岗位、法律权利和市场反馈，重新分配了提出、表述、选择、批准、执行、检验和修正形式的权限。这种重新分配并不同步，也没有彻底消除现场判断、手工知识和家庭劳动。

该论点是**待证假设**，不是冻结结论。若中心机制生死门未通过，必须修改论点和章节结构，不得继续寻找材料证明预设结论。

### 2.4 通向第二章

第一章解释生产关系内部的形式判断、表述媒介和权限分化。第二章解释工业产品如何进入展览、教育、消费、公共审美和国家竞争。

第一章只处理：

- 企业和工场内部的岗位名称；
- 制图、制模、样品和规格的生产权限；
- 专利、注册、合同和企业产权中的称谓与权利；
- 与生产组织直接相关的职业分化。

第一章不系统展开：

- 设计教育改革；
- 博物馆、展览和公共收藏；
- 公共审美评价；
- 国家竞争与“优良设计”治理；
- 以社会改良为目的的设计制度。

上述内容仅在解释生产机制不可缺少时作最小交代，并把主要论证留给第二章。

## 三、核心概念的操作性判据

### 3.1 三种不同的“设计”层次

全章必须区分：

1. **历史词语**：历史行动者实际使用的词及其语境，例如图样、制图、工业艺术、装饰艺术或其他岗位称谓；
2. **分析概念**：教材作者为比较不同生产关系而使用的“设计性判断”或“形式决定权限”；
3. **后设身份**：后来设计史、企业宣传或专业制度追认的“设计师”“先驱”和作者身份。

历史行动者没有使用“设计”一词，不等于没有形式判断；参与产品形成，也不等于已经拥有设计权限或专业设计身份。

### 3.2 活动分类

不把任何影响产品形式的活动都称为设计。证据记录和正文采用三级分类：

| 层级 | 名称 | 最低判据 | 可写结论 |
|---|---|---|---|
| I | 产品形成劳动 | 某项劳动对产品结果产生可观察影响，但尚无方案选择或权限证据 | 只能写“参与产品形成” |
| II | 设计性判断 | 制作完成前存在形式或工艺选择；行动者在两个以上可能方案、参数或处理方式之间作出判断，并具有相应的提议、解释、修改、检验或否决权限 | 可讨论“形式判断”及其边界 |
| III | 制度化设计活动 | 第二层成立，且决定通过图样、模型、样品、规格、语言或其他媒介跨工序／地点传递，或被岗位、合同、课程、法律、企业程序明确识别 | 可讨论设计活动的分化、外化或职业化 |

不能仅凭工资册、岗位存在、形式变化、市场销量或后来的作者署名，把第一层直接升为第二或第三层。

### 3.3 七项识别维度

对每项拟称为“设计性活动”的材料，逐项检查：

1. **预先性**：决定是否发生在制作完成以前；
2. **外化性**：决定是否通过图样、模型、样品、规格或语言被表达；
3. **比较性**：是否存在方案、参数或处理方式之间的取舍；
4. **授权性**：行动者是否具有提出、选择、批准、解释、修改、检验或否决权限；
5. **跨工序性**：决定是否传递给其他劳动者、部门或地点；
6. **反馈性**：误差、生产结果、销售或使用是否反向改变决定；
7. **制度识别性**：活动是否被岗位、合同、法律或组织程序识别。

第二层至少必须同时证明预先性、比较性和一种实际权限。第三层还须证明跨工序传递或制度识别，不能用指标数量机械凑分。

### 3.4 “形式决定权”的权限矩阵

| 权限 | 核心问题 | 不能替代它的材料 |
|---|---|---|
| 提议权 | 谁能提出形式或工艺方案 | 仅证明受雇的工资册 |
| 选择权 | 谁能在多个方案中选择 | 只有一个成品的图像 |
| 批准权 | 谁能使决定进入生产 | 单独的署名或企业归属 |
| 表述权 | 谁把决定转化为图样、模型、样品或规格 | 不能证明实际使用的图样存世 |
| 解释权 | 谁在现场解释不完整或不可执行的指令 | 无现场关系的岗位名称 |
| 修改权 | 谁能根据材料、误差或成本改变方案 | 仅有产品差异 |
| 检验权 | 谁判断产品是否合格并要求返工 | 企业宣传中的质量声明 |
| 署名权 | 谁被公开承认为作者 | 实际形式决定权限 |
| 法律权 | 谁拥有专利、注册或企业产权 | 实际发明、制作或修正行为 |
| 市场筛选权 | 订单、销售、投诉和使用怎样影响下一轮生产 | 直接参与当次形式决定 |

正文每次使用“权力”“控制”“决定”时，必须指明其中一种或数种具体权限。

## 四、时间结构

1750—1914年不得被写成一个静止的“工业时期”。每节至少辨认下列三个阶段中的变化；具体分界和地区差异须在证据核验后调整。

| 暂定阶段 | 主要观察对象 | 本章要检验的变化 |
|---|---|---|
| 约1750—1800 | 作坊、家庭外包、工场、早期机械化 | 构思和制作知识怎样分布；机器进入了哪些局部工序 |
| 约1800—1850 | 工厂组织、专利与注册、工程制图、市场扩张 | 表述媒介和监督怎样跨越工序；现场判断是否被压缩或重组 |
| 约1850—1914 | 企业扩张、批量体系、跨国生产、岗位分化 | 权限怎样制度化；混合生产和地区差异怎样继续存在 |

时间变化进入正文的方法：

- 每节先说明早期条件，不从后期职业名称倒推；
- 中段说明机制怎样被制度化或扩大；
- 后段说明同一机制怎样变形、受限或在不同地区产生不同组合；
- 不能用章外时间轴代替正文中的变化。

## 五、框架冻结前的中心机制生死门

### 5.1 必须取得的连续证据链

至少取得一组属于同一对象、同一企业／工场或可证明直接关联的材料，能够连续说明：

> 形式或工艺方案被提出  
> → 通过图样、模型、样品、规格或语言外化  
> → 传递到另一工序、劳动者或地点  
> → 在生产中被执行  
> → 通过检验、误差、返工或使用暴露结果  
> → 被解释、修正、拒绝或反馈到下一轮决定

### 5.2 生死门判定

| 结果 | 处理 |
|---|---|
| 连续链成立，且能识别至少三种不同权限 | 可以保留“权限重新分配”为中心主线，继续冻结两个锚点案例 |
| 只能证明图样／模型存在，不能证明生产执行 | 降级为媒介史问题，不得写“构思与制作分离” |
| 只能证明生产分工，不能证明方案选择和权限 | 改写为劳动组织史，不得称为设计活动分化 |
| 只能证明署名、专利或企业产权 | 改写为作者／权利归属史，不得替代实际生产判断 |
| 无法取得同一关系链 | 放弃当前中心论点，重新设计章节结构 |

在该生死门通过前：

- 六节题名和论点均为暂定；
- 锚点案例不得冻结；
- 图像清单和教学组件不得展开；
- `03-正文.md`保持锁定。

### 6.2 1.1 在“设计”之前：历史词语与分布式造物知识

**本节问题：** 在专业设计身份形成以前，哪些人参与形式判断；教材作者应怎样命名这些活动？

**论证任务：**

1. 前置区分历史词语、分析概念和后设职业身份；
2. 比较作坊、行会、家庭劳动和工场中的知识传递；
3. 使用三级活动分类，避免从“参与产品形成”直接跳到“设计”；
4. 建立后文统一指标：谁能提议、选择、表述、解释、修改和检验。

**时间变化：**

- 先处理约1750年前后延续的组织基线；
- 再观察18世纪后半叶外包、工场和早期机械化怎样改变知识位置；
- 不使用19世纪后期岗位名称回写早期行动者。

**区域嵌入：**

英国与选定比较地区的作坊、家庭劳动和样品／图样传递在本节首次并置，不把非英国材料留到1.6才出现。

**转折：**

本节说明已有多种形式判断，却尚未解释生产规模变化为何会提高跨工序协调的需要。

### 6.3 1.2 尺度变化：机器、能源、市场与协调问题

**本节问题：** 机器、能源和市场改变了哪些具体工序、距离和重复要求？

**论证任务：**

1. 以时间变化组织机器、能源、运输和市场，不作平行名词清单；
2. 区分局部机械化、工厂组织、批量增加和标准化；
3. 说明规模变化产生的协调问题，但不据此宣布设计已经形成；
4. 比较同类机器进入英国与比较地区不同工序后的差异。

**时间变化：**

- 约1750—1800：机器进入局部工序，与家庭和作坊并存；
- 约1800—1850：工厂和运输扩大跨工序、跨地点协调；
- 约1850—1914：企业与批量体系扩大，但现场修整和混合生产继续存在。

**区域嵌入：**

选定的棉纺／印花比较对贯穿本节，使用相同指标比较机器进入工序、劳动组合、市场距离和样品权限。

**转折：**

规模变化只能说明为何需要协调，下一节必须证明协调怎样通过媒介和权限作用于形式。

### 6.4 1.3 表述媒介与决定权限：图样、模型、样品和规格

**本节问题：** 形式判断怎样被外化、传递、执行、检验和修正？

**论证任务：**

1. 分别界定图样、模型、样品、工作图和规格，不互作近义词；
2. 用一条连续证据链追踪提出—外化—传递—执行—检验—修正；
3. 使用权限矩阵识别各行动者的具体权限；
4. 比较媒介作为参照、协商工具和强制指令的不同状态；
5. 处理至少一项指令被现场解释、修改或拒绝的材料。

**时间变化：**

同一媒介不能跨时期被视为权力不变。须比较其复制范围、组织位置、法律地位和现场权限怎样变化。

**区域嵌入：**

比较地区的样品、图样或口传—实物传递必须与英国材料使用相同问题；没有直接可比材料时明确不可比，不用形式相似代替。

**停写条件：**

本节不能取得连续证据链时，全章不得以“设计与制作的相对分离”为中心主线。

### 6.5 1.4 两条生产链：材料如何进入形式

**本节问题：** 材料、工序和权限怎样在具体对象中共同形成可观察的形式？

**论证任务：**

1. 只分析两个锚点对象，不铺开棉、陶瓷、铸铁、钢、玻璃和家具名录；
2. 每条链都按“材料来源—方案与媒介—生产组织—现场修正—形式结果—销售／使用反馈”展开；
3. 比较两条链中相同权限由不同岗位承担的情况；
4. 对象细读必须服务于中心机制，不以风格描述替代。

**锚点选择：**

- 锚点A方向：具体印花棉布及其样本—制版—印染—销售链；
- 锚点B候选：具体陶瓷器或铸铁构件，二者择一；
- 只有通过 `02-证据与注释.md` 中的锚点门槛后，才能写入具体对象名称。

**区域嵌入：**

锚点A同时承担跨区域生产链比较，不另设材料“全球背景”。锚点B优先承担另一种组织或材料机制，不为追求地理覆盖而选择。

**转折：**

两个对象说明形式由多种权限共同形成，下一节检验具名作者、现场劳动和市场反馈之间不能互相替代的作用。

### 6.6 1.5 生产现场的判断：具名作者、匿名劳动与市场反馈

**本节问题：** 谁只是参与生产，谁拥有形式判断；署名、法律权和实际修改权怎样错位？

**论证任务：**

1. 不再使用“匿名设计”作为预设标题；
2. 用权限矩阵区分具名作者、企业主、制图员、制模工、监工、熟练工和其他劳动者；
3. 只有出现材料调整、指令解释、方案修改、检验否决或稳定变体证据时，才讨论现场劳动者的设计性判断；
4. 区分当次形式决定与市场对后续生产的间接反馈。

**市场反馈分级：**

| 情形 | 可写程度 |
|---|---|
| 用户直接提出定制要求并进入方案选择 | 可讨论直接参与形式决定 |
| 商家转述订单 | 讨论中介后的需求，不称用户共同设计 |
| 企业根据销量推测需求 | 讨论市场筛选，不称直接设计 |
| 维修暴露结构问题并引发修改 | 讨论反馈机制，须证明修改链 |
| 后续人员主动解释投诉或使用数据 | 讨论企业内部再设计，不把解释归于用户 |

**区域嵌入：**

比较现场判断在工厂、家庭和作坊—机器混合生产中的不同权限，不把混合生产仅作为章末反例。

**转折：**

实际权限并不等于公开身份，下一节综合不同地区的权限分化，并处理生产组织边界内的职业命名。

### 6.7 1.6 不均衡的分化：跨区域比较与职业命名

**本节问题：** 权限重新分配为何在行业和地区中不同步；哪些活动开始被岗位、合同或法律识别？

**论证任务：**

1. 综合前五节已经出现的区域材料，不在本节首次添加多个地区；
2. 只保留一个有充分证据的比较对；
3. 比较能源与机器进入工序、组织组合、表述媒介权限、法律权和市场反馈；
4. 职业命名仅处理企业岗位、合同、专利／注册和生产组织；
5. 教育、展览、公共审美和国家竞争只作为第二章问题提出。

**暂定比较方向：**

- 英国棉纺／印花体系与南亚棉纺织和混合生产；或
- 英国工厂体系与奥斯曼家庭—作坊—机器混合体系。

二者只选其一。选择依据是能否使用同一指标取得连续证据，而不是地区代表性。

**章末功能：**

本节得出的应是“不均衡分化”的条件性判断，不是从英国向世界扩散的阶段模型。

## 七、案例架构：2＋2＋1

具体案例尚未冻结，只冻结功能结构：

- 支持案例二：专利、设计注册或权利争议；

任何类别方向都不是具体案例。对象名称、年代、机构和材料链未核定前，不得进入开篇、图像清单或正文。

## 八、证据独立性

“两条独立证据”不是数量要求。判断独立性时检查：

1. 来源机构是否不同；
2. 作者或生产者关系是否不同；
3. 材料类型是否不同；
4. 形成目的和受众是否不同；
5. 是否存在直接抄录、同一数据或共同档案依赖；
6. 是否能从不同角度检验同一机制。

同一企业的专利、目录和宣传册属于不同文本类型，但未必是独立来源。核心机制优先使用“制度／企业表述＋生产记录／实物＋外部研究或使用记录”的异质组合。

## 九、本章专用停写条件

出现以下任一情况，不得解锁正文：

1. 未通过中心机制生死门；
2. 两个锚点对象尚未确定或不能完成对象身份核验；
3. 只有媒介存世，不能证明媒介进入生产执行；
4. 只有劳动存在，不能证明方案选择和具体权限；
5. 把专利、注册、署名或企业归属当作实际形式决定；
6. 比较地区不能使用相同问题和指标；
7. 区域材料只在最后一节出现；
8. 1.6越界承担教育、展览、公共审美或国家竞争主论证；
9. 文献独立性只按数量判断；
10. 具体图像和教学组件先于锚点对象冻结。
