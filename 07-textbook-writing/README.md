# 《现当代设计史》教材撰写工作区

本目录用于集中管理《现当代设计史》（设计学理论专业）的总纲、章节工作包、正文草稿、图像与版权、审校记录和出版交付文件。

## 目录结构

| 目录 | 用途 |
|---|---|
| `00-总纲与规范/` | 教材总纲、统一章法、术语表和编写规范 |
| `01-章节工作包/` | 各章摘要、核心论点、案例卡、证据表和参考文献分级表 |
| `02-章节草稿/` | 按编、章管理的正文初稿与修订稿 |
| `03-图像与版权/` | 图像需求、图注、来源、授权和替代方案 |
| `04-审校与版本/` | 事实核查、同行审阅、课程试用和版本变更记录 |
| `05-出版交付/` | 定稿、附录、索引、书目及出版方交付清单 |

## 文件流转

```text
总纲与规范
→ 章节工作包
→ 章节草稿
→ 证据与图像核验
→ 学术审校和课程试用
→ 全书统稿
→ 出版交付
```

## 管理原则

1. 根目录语料和研究报告只作为材料来源，不在本目录重复保存。
2. 正文论断必须能够回查项目原始文本或合法取得的一手材料。
3. 项目报告用于检索和证据定位，不替代原文核对。
4. 每章草稿与证据表同步更新，避免先写结论、后补来源。
5. 图像在进入定稿前必须记录来源、权利状态和出版许可。
6. 重大结构调整写入 `04-审校与版本/版本记录.md`。
