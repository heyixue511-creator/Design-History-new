# 《现当代设计史》逐章写作区

本目录只用于《现当代设计史》（设计学理论专业）的教材写作。当前保留总纲与规范；既有样章、工作包、审校记录和出版流程文件已经清理。后续按照教材章节顺序逐章建立、逐章完成，不同时维护多套草稿。

## 一、固定依据

所有章节开始撰写前，必须先读取`00-总纲与规范/`中的三份文件：

1. `教材总纲-现当代设计史（设计学理论专业）.md`：确定章节位置、核心问题、结构和材料边界；
2. `教材统一编写规范-v1.0.md`：确定证据、引文、图像、术语和审校要求；
3. `《艺术与观念》写作样例与语言语序规则-v1.0.md`：确定历史叙事、对象细读、段落推进和语言语序。

三份文件共同生效。章节草稿不得自行改变全书结构；需要调整总纲时，先修改`00-总纲与规范/`中的对应文件，再开始正文。

## 二、全书文献匹配前置流程

逐章写作开始前，必须先完成项目文献的全量读取与全书分配。全量读取的目的不是形成孤立的书目摘要，而是把每一项文献准确分配到教材各章，防止漏配、错配、仅凭标题判断相关性，或者同一文献在多章中无原则重复使用。

读取和匹配须遵守以下顺序：

1. 全文读取原始书籍、原始论文和“写作参考体例”文献，不以目录、摘要、关键词或研究报告代替全文；
2. 全文读取书籍深度报告、论文深度报告和增强报告，用于发现议题、人物、机构、案例及文献之间的关联；
3. 将报告中的判断逐项回查原文；报告负责检索和提示，原文负责支持正式论断；
4. 按总纲的章、节和核心问题建立“全书章节—参考文献分配矩阵”，记录文献可支持的章节、具体问题、证据类型、相关页段及使用优先级；
5. 对跨章文献区分“主归属章”和“可交叉引用章”，说明各章使用角度，避免重复叙述；
6. 对尚无充分文献支持的章节明确标记缺口，不得以相邻主题文献替代，也不得先写确定性结论再补来源；
7. 完成重复版本核对和覆盖审计，确认全部纳入范围的文献均已被读取、判断并分配或说明“不采用”理由。

文献分配以内容的实际论证范围为准，不以书名、文件名或单个关键词直接匹配。每章启动前，还须从全书分配矩阵中提取该章文献，形成独立的`01-本章文献映射.md`，并在正文写作过程中持续回查。

## 三、逐章建立目录

只有在某章正式启动时，才建立该章目录：

```text
07-textbook-writing/
├─ 00-总纲与规范/
├─ 第01章-章名/
│  ├─ 00-章节提纲.md
│  ├─ 01-本章文献映射.md
│  ├─ 02-证据与注释.md
│  ├─ 03-正文.md
│  ├─ 04-图像与图注.md
│  └─ 05-审校记录.md
└─ README.md
```

不预先建立空章节，不再拆分“工作包”“草稿”“审校”和“出版交付”等平行目录。同一章的全部写作材料放在同一章目录中。

## 四、单章写作顺序

1. 从总纲提取本章核心问题、核心论点和5—7个正文小节，形成`00-章节提纲.md`。
2. 从全书章节—参考文献分配矩阵提取本章材料，形成`01-本章文献映射.md`；逐项记录文献路径、实际相关内容、适用小节、证据层级、精确页段、主用或辅用状态，以及跨章使用边界。
3. 根据文献映射核对主要材料、相互矛盾的解释和证据缺口，建立`02-证据与注释.md`。
4. 证据核验达到可写状态后撰写`03-正文.md`；正文中的关键判断、引文、争议和数据必须能回指本章文献映射及证据条目。
5. 确定正文对象后再建立`04-图像与图注.md`，不以配图代替史料。
6. 完成整章后进行文献覆盖、事实、逻辑、语言和立场审校，结果写入`05-审校记录.md`。
7. 本章通过审校后再启动下一章；未核定内容保留明确标记，不建立多个文件版本。

## 五、文献映射最低字段

每一条进入`01-本章文献映射.md`的文献至少记录：

- 规范书目信息和项目内原文路径；
- 全文读取状态，以及对应深度报告或增强报告路径；
- 与本章相关的具体论点、史实、对象、人物、机构或争议；
- 对应章、节及拟支持的正文判断；
- 一手文献、原始研究、综合研究或背景材料等证据类型；
- 精确页码、段落或可复核定位信息；
- 主用、辅用、对照、反例或暂不采用；
- 与其他章节的重叠范围及本章独有的使用角度；
- 证据缺口、版本问题、译名问题和待核事项。

“已读取”不等于“必须引用”。不采用的文献也应在全书覆盖审计中留下理由，以便确认不是遗漏。

## 六、文件与版本规则

- 每类内容只保留一个工作文件，直接在原文件上修订；
- 不使用`v0.1`、`v0.2`等文件名复制草稿，版本变化交由Git记录；
- 原始书籍、论文和研究报告继续保存在项目原目录，不复制到章节目录；
- 项目报告只用于检索和定位，正式论断必须回查原文；
- 不得仅依据文献标题、目录、摘要或关键词将其分配给章节；
- 每条正式参考文献必须经过“全文读取—章节匹配—原文定位—证据核验”四步；
- 未经核实的材料、身份判断和绝对化结论不得进入正文；
- 每章文件命名和内部标题必须与总纲一致。
