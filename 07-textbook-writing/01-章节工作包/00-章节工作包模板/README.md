# 章节工作包模板

每章在正文写作前建立以下文件：

| 文件 | 内容 | 完成门槛 |
|---|---|---|
| `00-章摘要.md` | 章功能、摘要、学习目标和关键词 | 能用300字说明本章为何存在 |
| `01-核心论点与问题链.md` | 总论点、分论点、反论点和章际过渡 | 每个分论点均有证据路线 |
| `02-三级提纲.md` | 节、目、段落任务和字数 | 总字数与章节规格一致 |
| `03-案例卡.md` | 对象、行动者、制度、形式和论证用途 | 至少含经典、普通、反例和转译案例 |
| `04-证据表.csv` | 论断、来源、锚点、审核状态 | 不把C级线索写成确定事实 |
| `05-图像清单.csv` | 图像、图注、论证功能和权利状态 | 每幅图均有替代方案 |
| `06-参考文献分级表.md` | 一级史料、核心研究和补充研究 | 核心论点至少双来源 |
| `07-材料缺口与补充计划.md` | 缺口、风险、行动和停止条件 | 明确哪些结论当前不可写 |

证据状态统一使用 `A/B/C/D`；写作状态统一使用 `READY`、`VERIFY`、`GAP`、`HOLD`。
