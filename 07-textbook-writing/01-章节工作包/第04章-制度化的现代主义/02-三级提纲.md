# 第四章三级提纲

## 开篇　1923年的一盏灯为何代表不了包豪斯（约800字）

- 从包豪斯灯的材料、制作、署名、展览和后世复制切入；
- 提出“名作如何被制度生产”的问题；
- 说明上一章的先锋媒介实验不足以解释学校、职业和生产体系的形成。

## 4.1 改革联盟与企业系统：制造联盟和AEG（约3000字）

### 4.1.1 制造联盟的组织前提

1. 19世纪设计改革、德国工业竞争和国家文化政策；
2. 穆特修斯、瑞曼、凡·德·费尔德等行动者；
3. 艺术家、工业家、教育者与政府之间的组织关系；
4. 制造联盟并非单一风格团体，而是利益与知识并存的改革网络。

### 4.1.2 标准化与个性表达之争

1. 类型化如何连接生产效率、质量规范与市场扩张；
2. 个性表达如何关联作者身份、文化价值与高端市场；
3. 1914年科隆展览作为公开冲突场；
4. 限定：制造联盟内部从未形成统一的现代主义纲领。

### 4.1.3 AEG与企业设计系统

1. 电气工业的潜在需求、消费教育与企业扩张；
2. 贝伦斯的职位、委托范围与团队协作；
3. 涡轮机厂的结构、表皮和企业纪念性；
4. 产品、商标、字体、印刷品和展览的协同；
5. 工人住宅与企业福利的治理功能；
6. 反例：AEG的跨媒介协同不等于后来意义上的完整企业识别手册。

对应证据：C4-01—C4-04。

## 4.2 魏玛包豪斯：共同体理想与基础课程（约3000字）

### 4.2.1 1919年的制度继承与共同体理想

1. 魏玛艺术院校合并与凡·德·费尔德遗产；
2. 《包豪斯宣言》的中世纪工坊隐喻；
3. 艺术家与工匠共同训练的政治含义；
4. “形式大师／工艺大师”双重领导；
5. 宣言目标、学校章程与实际运行之间的差异。

### 4.2.2 伊顿：身体、材料与感知训练

1. 基础课程在招生、筛选和分流中的制度位置；
2. 呼吸、节奏、明暗、色彩和材料研究；
3. 表现性、个体性与精神共同体；
4. 教师魅力、评价标准与教育权力。

### 4.2.3 莫霍利-纳吉和阿尔伯斯的课程改造

1. 平衡、结构、透明、光与技术实验；
2. 以有限资源发现结构可能的“材料经济”；
3. 从主观感知到媒介、生产和复制条件；
4. 基础训练的延续与变形；
5. 后世将课程简化为“平面、色彩、立体三大构成”的误读。

对应证据：C4-05—C4-08。

## 4.3 1923年的制度转向：艺术、技术与原型生产（约2000字）

### 4.3.1 “艺术与技术”的公共语境

1. 财政压力、公共展览和学校合法性；
2. 格罗皮乌斯与伊顿的分歧；
3. “艺术与技术的新统一”既是教学方向，也是公共沟通策略；
4. 将1923年写成渐变、协商和冲突，而非一日之内的风格替换。

### 4.3.2 号角屋：课程、工坊与生活实验

1. 不同工坊如何共同构造居住环境；
2. 展览样板、家庭模型与现实可复制性；
3. 技术设备、家务劳动和使用者假设；
4. 功能不是静态属性，而是不同主体之间的历史争论。

### 4.3.3 原型与生产条件

1. 单件实验、外部委托与批量生产之间的距离；
2. 包豪斯灯的材料、加工、署名和商品化；
3. 原型进入市场所需的标准、成本、企业合作与销售网络；
4. 限定：“适合机器生产”不等于“已经批量生产”。

对应证据：C4-09、C4-10。

## 4.4 德绍体系：建筑、媒介、工坊与劳动（约3500字）

### 4.4.1 迁往德绍与学校建筑

1. 从魏玛迁往德绍的政治与财政条件；
2. 德绍校舍如何展示教学和组织理念；
3. 建筑功能分区、交通与公共可见性；
4. 学校建筑既是使用空间，也是制度的自我形象。

### 4.4.2 摄影、排印与学校品牌

1. 莫霍利-纳吉的“新视觉”与媒介教育；
2. 拜耶的排印、出版和展览实践；
3. 建筑摄影、产品目录与出版物如何共同制造“包豪斯形象”；
4. 视觉统一与实际教学多样性之间的反差；
5. 正典化在学校主动组织自身形象时已经开始。

### 4.4.3 工坊、市场与性别分流

1. 工坊分流与职业机会；
2. 编织工坊的性别化及其技术创新；
3. 金属、家具、陶瓷等工坊的市场连接；
4. 性别规则如何进入材料、岗位、声望与收入分配。

### 4.4.4 学生劳动、署名与许可

1. 学生作品、教师署名和许可收益；
2. 普通劳动与明星作者的正典差异；
3. 学校、工坊、教师、学生和企业之间的作者权关系；
4. 证据边界：人数、收入与个案结论须回查专题档案。

对应证据：C4-11—C4-13；本节状态：`VERIFY`。

## 4.5 社会功能与学校政治：迈耶、密斯及关闭（约2200字）

### 4.5.1 迈耶：需求分析与集体方法

1. 集体主义、需求分析和社会功能；
2. 建筑部、外部委托与经济核算；
3. 项目如何把设计目标转换为用户、预算和施工条件；
4. “社会功能”内部仍存在技术、管理与政治张力。

### 4.5.2 政治冲突与校长更替

1. 学生政治、教师冲突和迈耶离任；
2. 密斯时期的专业化、建筑化和管理收缩；
3. 德绍关闭、柏林私立阶段与1933年终结；
4. 限定：校长更替不能写成纯粹的风格序列。

### 4.5.3 学校终结与制度遗产

1. 机构关闭与课程、人员、作品继续流动之间的区别；
2. 政治压迫如何改变现代主义的组织载体；
3. 为什么包豪斯的影响不能以1933年为简单终点。

对应证据：C4-14、C4-15。

## 4.6 迁徙、正典与亚洲转译（约2200字）

### 4.6.1 人员迁徙与课程再建

1. 教师和学生迁往欧美后的课程重组；
2. 个人经验、机构条件与当地教育传统的共同作用；
3. “传播”不是原样复制，而是制度组件的重新组合。

### 4.6.2 展览、出版与正典塑造

1. 展览、出版、博物馆和回忆录对包豪斯形象的塑造；
2. 建筑、字体和产品为何比行政档案与普通劳动更易进入正典；
3. 后世复制如何反向改变对历史原作的理解。

### 4.6.3 日本与中国的选择性转译

1. 日本对基础教育和工艺改革的选择性吸收；
2. 中国建筑、工艺美术和基础课程的多路径接触；
3. 区分直接传播、间接译介、平行实践和后设归类；
4. 避免以“影响”一词替代对人员、文本、课程和机构的具体追踪；
5. 过渡到第五章：企业、广告和消费市场构成另一条现代性路径。

对应证据：C4-16、C4-17。

## 章末教学组件（约1000字）

- 关键词辨析：标准化、功能、基础课程、工坊、社会功能；
- 史料实验室：比较1919年宣言、学校课程表和工坊产品目录；
- 争议题：包豪斯的主要遗产是形式、方法还是制度？
- 方法总结：如何用制度史重写一个被风格化的设计运动。
