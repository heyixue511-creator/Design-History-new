# 设计研究的概念化、制造、评价与世界建构

## 专题范围

本专题以Buchanan、Doordan、Margolin编《The Designed World》（2010）为核心，研究20世纪90年代至21世纪初英语设计研究怎样把设计对象从风格、形式和个人作者扩展到人工物、信息、材料、使用、组织、基础设施、环境和伦理后果。

核心来源：[book-0058：《The Designed World》](../summaries/book-0058.summary.md)。

这是一部从《Design Issues》重编的27篇论文文集，不是单一作者专著。总导言提出“概念化—制造—评价”三部分框架，各章却具有不同发表年份、论证方法和证据等级。专题综合必须保持作者区别，不能把全部论点归为三位编者的共同结论。

## 一、编者框架：设计研究不是风格目录

编者以如下转向描述设计研究：

1. 从形式属性研究扩展至心理、社会和文化语境；
2. 从历史／理论／批评分工转向彼此渗透；
3. 从设计领域内部概念转向哲学、人类学、社会学、管理、工程等交叉；
4. 从单件物转向传播、行动、服务、组织、环境和复杂系统；
5. 从功能评价转向价值与后果评价。

这可用于说明《Design Issues》周边学术网络在特定时期的自我定位，不能写成全球设计学自然、同步且一致的成熟史。中国、苏联与东欧、全球南方、黑人、原住民、女性主义、酷儿／跨性别和残障研究需用各自来源补入。

## 二、概念化：问题边界如何被设计

### 人工物不是自然的透明复制

Negrotti指出，再现自然对象必须选择范例、边界、观察层级与“本质性能”。材料和环境会制造超出意图的转形。这个框架适合追问模型怎样删减现实，却不构成当代AI、医疗装置或合成生物的安全结论。

### 信息不只有传播功能

Borgmann把信息区分为关于现实、用以实现现实和作为现实。其1995年数字批判是技术哲学史料；当代平台、社交媒体和大模型仍须使用近期经验研究。

### 物质关系超出符号和意图

Verbeek与Kockelkoren借脚本、多稳态和技术意向性说明：门槛、旋转门、微波炉等对象会在实际关系中组织行动。即使设计者没有明确排斥意图，也可能产生残障障碍或性别化劳动后果。

### 需要在扩散中被制造

Pantzar把技术“驯化”理解为玩具／工具、奢侈／必需、刺激／惯例的转化。商品、基础设施和制度共同塑造需要，但进化和自复制隐喻不能消除企业、政策与法律责任。

### 环境是生产和生活的内部条件

Chiapponi把生物圈、地圈、社会圈与技术圈并置；生命周期评价、拆解、收集和标准说明，可回收性不是材料标签。1998年的科学与政策判断必须更新。

## 三、制造：形式怎样由网络生成

### 反对“英雄设计师—被动执行”

本书的水族馆、OSS、Connection Machine、个人计算、数字排印、工程会议和税法案例表明，形式在技术、材料、组织、客户、使用者和传播条件中形成。设计史应重建角色、文件、预算、冲突和实施，而不是只追踪署名。

### 协作不等于平等

- OSS跨专业协作服务于情报、战争和国家权力；
- Day-Timers顾客参与也制造品牌忠诚和无偿反馈；
- Connection Machine的协作可见，但企业绩效和社会后果未被独立评估；
- 工程会议的修辞既可管理不确定性，也可柔化风险；
- 顾问项目中的客户仍可能掌握决定权；
- 软件和数字排印工具的扩散不等于价格、技能、劳动收益和接入平等。

因此，教材每遇“参与”“合作”“共同设计”，都应区分被观察、被咨询、共同构题、共同决定、否决和申诉。

### 制造也包括表达不可见系统

Connection Machine黑色立方体与红灯把并行计算架构转为可感形式；数字排印把字形、软件、屏幕、打印和设计劳动连接起来；可视化则通过选择和删减制造可见性。它们共同说明信息形式不是技术系统的透明外壳。

## 四、评价：设计后果怎样显露价值

### 评价不只是终端测试

编者把评价放在设计之前、之中和之后。Buchanan的善／有用／正义／愉悦、Manzini的社会质量、Madge的生态设计词汇史、Findeli的技术伦理，都要求说明何种生活值得追求、利益和风险怎样分配。

### 规范主张不能改写为结果事实

本书大量文章属于规范理论、演讲和研究札记。它们可以证明“作者提出什么”，不能证明：

- 课程已经提高伦理判断；
- 绿色设计已经降低总环境影响；
- 参与已经改变决策权；
- 数字技术已经民主化生产；
- 信息展示已经提高学习；
- 系统设计已经产生公共正义。

结果判断必须另有调查、实验、长期数据、档案和受影响者证词。

### 评价本身具有政治性

《Colors》案例揭示，多样性视觉可用“我们都一样”抹去冲突，并将宽容置于主导群体许可之下；乌尔姆案例显示课程科学化、企业合作和社会改革理想发生冲突；生态设计中的LCA也受系统边界、数据和委托方价值影响。

## 五、设计教育与制度史

Paul Betts的乌尔姆研究是本书最重要的机构史材料。它用市档案、课程、演讲和校刊重建：

- Inge Scholl、Otl Aicher的反法西斯民主教育目标；
- Max Bill的艺术家—设计师模式；
- Maldonado推动的科学化、社会科学和方法课程；
- Braun、Gugelot、Rams等产业合作；
- 州政府、财政、内部派别、理论／实践冲突与1968年关闭。

该章支持乌尔姆和战后德国设计教育，不支持呼捷玛斯，也不能承担中国院校、官方政策、行业组织、学科史和院校清单。中国设计教育必须另建中国制度材料链。

## 六、数字设计史与AI边界

本书提供1980—90年代的重要数字史片段：

- Thinking Machines与Connection Machine的工业设计；
- 个人计算机、Homebrew、Apple与用户重新用途化；
- Macintosh、PostScript、PageMaker、数字字体和屏幕语言；
- 当时关于AI、电子村落和信息社会的预测。

这些材料只能说明历史行动者怎样想象计算未来。它们不能证明当代大模型理解力、创造力、文明影响、偏见、版权、劳动替代或治理成效。教材第16章AI与设计伦理必须使用近期论文、政策文件和可复核评估，并明确“谁提出、基于什么证据、适用到何种范围”。

## 七、生态与可持续设计的词汇史

第7—9、22、25、26章形成一组1990年代环境设计话语：

| 方向 | 主要问题 | 证据边界 |
|---|---|---|
| 产品寿命与维修 | 技术、经济和心理寿命 | 需补生产者责任、技能与可负担性 |
| 技术—环境系统 | 生命周期、拆解、回收基础设施 | 当前标准与绩效需更新 |
| 社会质量 | 服务、照料、少物质生活 | 自由选择受制度和不平等限制 |
| 绿色／生态／可持续 | 术语更替、漂绿和专业组织 | 不是线性进步规律 |
| 生物亲和 | 自然／文化与情感关系 | 遗传论证不足，原住民被浪漫化 |

生态问题必须补入环境正义、殖民开采、工人、地方社区、原住民主权、能源和供应链。

## 八、种族、殖民、性别、亚文化与残障立场

- Loos文本中的Papuan—罪犯—儿童等级必须作为种族主义史料批判；
- Veblen学派的“野蛮／文明”进化分类已经过时；
- Thiel和Stairs虽批评现代工业，却继续浪漫化“原始／土著”和Inuit；
- 《Colors》涉及种族、HIV、酷儿、亚文化和白人至上主义，须保持明确批判立场；
- 女性常被安排为助手、家庭劳动承担者或视觉对象；
- 门槛和旋转门提供残障排斥入口，但残障者不是主要知识生产者。

教材不得以“多样性”修辞遮蔽权力，也不得复制白人至上主义标志、旗帜、国家／党派徽记或地图。

## 九、证据分级

### P1：较强机构／过程证据

- Betts的乌尔姆档案与课程史；
- Katz的OSS解密档案、内部文件和访谈；
- Thiel的Connection Machine参与者记述；
- Lloyd／Busby明确说明时长、会议数量和记录方式的微观案例。

P1并不等于无偏见。档案选择、作者位置、样本范围和缺席群体仍须说明。

### P2：理论与行动者材料

- Buchanan、Negrotti、Jonas、Borgmann、Manzini、Findeli等规范理论；
- 专业人员对环境、数字排印、设计批评和企业实践的解释；
- 编者对设计研究“成熟”的学科叙述。

适合写“某作者如何理解”，不适合直接写“历史已经如此发展”。

### P3：需降级或拒绝的判断

- 过时医学、感染、维生素和AIDS论断；
- 生物亲和遗传论、进化类比和“已证明替代方案”；
- 对中国医学、Inuit、Papuan、原住民和“第三世界”的本质化概括；
- 20世纪90年代对互联网、AI和虚拟现实的现实外推；
- 未经验证的民主化、学习、保护行为和生产率效果。

## 十、与教材章节的匹配

| 教材问题 | 使用方式 |
|---|---|
| 现代设计概念如何扩展 | 用总导言和四阶框架说明问题范围，标明编者／作者立场 |
| 现代主义及其批评 | 用Veblen、Loos、Branzi、Banham作理论和修辞史 |
| 战争、信息与制度 | 用OSS案例，保持战争与权力批判，不使用禁用图像 |
| 战后设计教育 | 以乌尔姆为主要入口，再与专项校史互证 |
| 数字设计形成 | 连接Connection Machine、PC参与和数字排印 |
| 可持续设计转向 | 比较寿命、LCA、服务、词汇和生态哲学 |
| 设计伦理与社会责任 | 区分规范框架、过程证据和结果证据 |
| 设计学科史 | 把本书作为英语期刊网络的行动者叙述，不作全球总论 |

## 十一、明确不采用

- 地图、地图式图表、旗帜、国徽、党徽、国家或党派象征；
- 白人至上主义组织的旗帜与徽记；
- MUJI；
- 以本书补呼捷玛斯、中国设计教育政策、行业组织和院校清单；
- 以Hirst说明中国医学或公共卫生；
- 以Stairs说明Inuit或原住民设计；
- 以1990年代文章证明当前AI或平台效果；
- 将四阶设计写成线性等级；
- 将参与或协作直接等同民主、共同决定或正义。
