# 现代设计通史、全球去中心化与教材叙事

## 专题范围

本专题以[book-0102：David Raizman《History of Modern Design》第三版](../summaries/book-0102.summary.md)为核心，并以[book-0103：同书第二版](../summaries/book-0103.summary.md)进行版本对读，处理一部现代设计教材如何同时保持年代可读性，并把生产、消费、商业、教育、殖民交换、性别、劳动、媒介、日常使用和设计伦理纳入叙事。

## 版本史增量：2010第二版到2023第三版

第二版已经建立六部十六章及“材料／技术—劳动与制造—企业／政府／学校—营销与媒体—对象／服务—使用与风险”的稳定骨架，也已纳入服装、室内、大众文化、性别排斥、安全、环境、GUI、AI前史和服务设计。第三版的关键变化不是另写一部书，而是把第二版零散的国际比较明确改写为`taste、gender、globalism`与de-centering，并增加六个`Global Inspiration`，再把正文终点由2010延至2020。

由此形成三条教材原则：

1. book-0102与book-0103是同一作者同一书的不同版次，不能当作两项独立证据；
2. 第二版用于确认某一叙事在2010年已经出现，第三版用于观察正典如何补入全球、性别、种族和环境议题；
3. 两版共同保留的命题更值得追索，却仍须沿各版参考书目回到原始档案和专题研究。

第二版没有六个全球专题，其中国材料主要停留在瓷器／异域趣味与2008国家形象案例，日本战后设计相对完整；这正好显示第三版为何需要显式去中心化，也显示“增加插入专题”仍未彻底改变欧美主体章节骨架。

原书2023年出版，共1,690,332字符，含导论、六部、十六章、六个`Global Inspiration`、参考书目、图片出处、引文来源和索引。主体时间范围止于2020年；575幅本地图像全部缺失。

## 一　通史不是作品目录

Raizman把每个设计对象置于多层关系：

| 层级 | 追问 |
|---|---|
| 材料 | 原料从哪里来，由谁开采、种植、加工？ |
| 制造 | 工具、机器、工场、分工和技能如何组织？ |
| 委托 | 国家、企业、零售商、博物馆或个人如何设定目标？ |
| 设计劳动 | 署名者之外有哪些工程师、制图员、工人和协作者？ |
| 流通 | 展览、目录、广告、商店、信用和运输如何建立市场？ |
| 使用 | 谁购买、谁使用、谁维护，物件如何进入日常生活？ |
| 权力 | 阶级、性别、殖民、种族、国家和环境代价如何分配？ |

教材正文不能使用“人物—风格—代表作”三项循环。适合采用：

```text
对象或事件
→ 制造与制度条件
→ 同期行动者的主张
→ 市场和使用
→ 矛盾、排除及证据边界
```

## 二　年代叙事怎样避免目的论

原书仍按1700—2020推进，但每一时期都安排冲突方法：

- 宫廷工场与商业制造并存；
- 手工改革与工业扩张并存；
- Art Deco奢侈工艺与Modernism标准化重叠；
- Bauhaus、构成主义、De Stijl、北欧和美国工业设计不是同一路线；
- 战后“好设计”与大众文化互相借用；
- 后现代主义、亚文化、社会设计和企业创新共享同一市场；
- 数字化带来便利，也扩大监控、劳动替代和环境责任。

因此，章节转折不宜写成“旧风格被新风格彻底取代”。更准确的转折语是：

- “与此同时，另一种生产／使用逻辑正在形成”；
- “这种原则在展览与宣言中清晰，在大规模生产中却有限”；
- “形式上的简化并未同步降低制造复杂度”；
- “后来的经典化放大了教育与传播影响，却遮蔽了当时市场规模”。

## 三　“去中心化”的成效与边界

第三版在六部末加入中国与汉字文化圈、穆斯林西亚与北非、中西非、美洲、日本以及重访中国。它证明欧洲／北美设计依赖：

- 中国瓷器、漆、茶和出口生产；
- 西亚、北非装饰、旅行、收藏和殖民展示；
- 西非纺织、蜡染、全球贸易与殖民原料；
- 美洲原住民、Hispanic、Mexico、Argentina和Brazil的地方现代性；
- 日本政策、企业、民艺、出口和国际赛事；
- 中国制造、消费、公共事件建筑和全球供应链。

但六个专题仍被插在欧美主体章节之后，且多由英语研究、欧美博物馆和作者旅行经验中介。教材使用时应把它们标为“连接线索”，再补：

1. 本地作者和本地语言研究；
2. 生产者、工匠、使用者和受影响群体材料；
3. 殖民制度、贸易数据和供应链档案；
4. 当地学校、企业、行业组织和政策史。

## 四　生产与消费是共同主线

### 18世纪

法国王室工场说明设计行政、宫廷礼制和专业工艺；英国Wedgwood、图册和零售网络说明商品系列、模具、样品、代理和声望营销。现代设计的发生不是“机器突然出现”，而是需求、供给、制造、销售和身份判断同时变化。

### 19世纪

工业扩张增加数量和速度，也催生“好设计”焦虑。Cole、Jones、Schools of Design、Museum和Great Exhibition把味觉改革制度化。标准由谁制定、以何种藏品教学、把哪些文化变成ornament资源，本身就是设计史。

### 20世纪

Ford大规模标准化与GM年度样式是不同商业制度；MoMA“Good Design”和大众广告不是纯粹对立；消费者受到设计和营销引导，也可能拒绝产品、重释对象或形成亚文化。

### 当代

服务、界面、数据与平台没有取消物质生产。电子产品仍依材料、制造、物流、能源、维护和废弃体系。教材第十六章应继续使用“物质—数据—劳动—治理”链，而不是只写屏幕形式。

## 五　味觉、正典和制度

本书将`taste`从审美好恶转为制度问题：

- 王室、行会与宫廷决定奢侈品等级；
- 改革者把经典原则写入教育；
- 百货和广告把时尚变化转为消费节奏；
- Museum和展览选择哪些物件代表现代性；
- 企业以品牌体系规范产品家族；
- 设计史教材再一次选择人物、地区和作品。

所谓正典不是虚构，它由真实物件、学校、出版、收藏和展览长期累积；但其代表性必须审计。对Bauhaus、MoMA、Ulm、Braun、Eames等，应同时登记：

- 当时产量与市场覆盖；
- 教育、展览与出版的后世放大；
- 被弱署名的女性、工程师和工人；
- 拉丁字母、欧美家庭和中产消费假设；
- 哪些地区的现代设计被排除。

## 六　现代主义应以“多种制度”而非单一形式写

| 体系 | 核心机制 | 不宜简化为 |
|---|---|---|
| De Stijl | journal network、绘画／空间实验、家具与家庭协作 | 红黄蓝几何风格 |
| 构成主义 | 革命机构、宣传、摄影蒙太奇、生产理想 | 抽象形式 |
| 呼捷玛斯 | 高等技术艺术教育与苏俄先锋网络 | Bauhaus俄国版 |
| Bauhaus | 校制、基础课、工作坊、展览、迁移 | 少数经典家具 |
| U.A.M. | 法国现代材料、室内和企业委托 | Art Deco对立面 |
| 北欧现代主义 | 福利、出口、工艺、工业与地区材料 | 天然温和民族性 |
| 美国工业设计 | 企业策略、咨询事务所、工程、styling、博览会 | 五位“设计大师” |

Raizman直接提到`Higher State Technical Workshops／Vkutemas`，足以证明总纲不能遗漏呼捷玛斯；其材料不足以重建教育体系。详细写作仍回[专题02](02_构成主义、呼捷玛斯与包豪斯.md)和[专题71](71_俄国先锋建筑、呼捷玛斯教学与竞赛图纸.md)。

## 七　手工／机器不是二元对立

本书跨三个世纪持续拆解这一二分：

- Morris反对异化生产，但其企业依赖富裕客户；
- Art Nouveau手工表面依赖工业、商店和国际材料；
- Art Deco几何简洁可能需要稀有材料与复杂工艺；
- Bauhaus从手工工作坊转向艺术与技术，商业产量仍有限；
- 北欧、意大利、日本把工艺知识与工业生产结合；
- 当代3-D printing、biofabrication和digital craft重新组织技能，而非消灭工艺。

教材用语应写“手工与机器的关系被重新组织”，少用“机器取代手工”。

## 八　设计教育的制度链

原书可建立比较框架：

1. 法国王室工场：行政、图样和专业工艺；
2. South Kensington：学校、博物馆、展览与工业竞争；
3. Arts and Crafts行会：劳动伦理、共同体和企业矛盾；
4. Werkbund：类型化、国家竞争与工业合作；
5. Vkhutemas：革命制度中的高等技术艺术教育；
6. Bauhaus：基础课、工作坊、校长阶段、性别分流和迁移；
7. Ulm：形式教育转向科学、系统、社会和企业合作。

本书不含中国设计院校、官方政策、行业组织、学科史和主流院校清单。中国设计教育章节必须另建政策—组织—院校—课程—教师—学生—行业证据链。

## 九　图像、广告和“客观性”

书中从Chippendale图册、Great Exhibition、Art Nouveau poster、Futurist typography、Constructivist photomontage、New Typography、Isotype、杂志艺术指导、企业识别到digital type，显示平面传播不只是风格：

- 它选择什么信息可见；
- 决定用户行动顺序；
- 建立企业和机构的一致性；
- 把政治、商业或社会目标包装为“清晰”；
- 通过摄影、比例、剪裁和网格产生情感。

Isotype、新字体和International Typographic Style的清晰主张必须与转换者、受众、语言系统和动机并写。地图／类地图图像依项目规则排除。

## 十　大众文化与亚文化的立场分析

原书以汽车、郊区、摇滚、Pop、Punk、psychedelia和underground graphics纠正高／低文化二分。教材使用亚文化材料需完成五项判断：

1. 参与者是谁，是否存在内部差异；
2. 视觉／服饰／音乐在何种具体行动中使用；
3. 它针对何种制度、代际或市场；
4. 媒体和企业如何放大、改造或商品化；
5. 谁因性别、种族、阶级、毒品、暴力或法律风险受影响。

Punk、Bikiniarze、1960年代反文化都不能被写成统一进步力量，也不能只以刺激性图像证明立场。

## 十一　性别、种族和“白人正典”

第三版主动补女性和有色人种设计者，并承认技术进步史常以教育、工资和机会排除他们。教材不应把“加入几个代表人物”当成修正完成。

需要从四个层面写：

- **准入**：学校、工作坊、专业组织允许谁进入；
- **分流**：Bauhaus女性为何集中在weaving，谁能进入metal workshop；
- **署名**：Schröder-Schräder、Perriand、Pineles、工程师和团队如何被弱化；
- **使用与劳动**：厨房、郊区住宅、家电、时尚和办公室怎样分配照护、身体和职业劳动。

第十五章提到旧史多为男性、欧美和白人，是对制度性正典的批评。教材应保留这一分析功能，不把“白人”变成脱离关系的一般人物标签。

## 十二　殖民材料、奢侈与全球供应链

本书提供多处重新解释经典设计的入口：

- 法国家具与稀有木材、象牙；
- 中国瓷器、漆器、茶与欧洲消费；
- 西亚／北非装饰与Orientalism；
- Art Nouveau、Belgian Congo、橡胶和象牙；
- Vlisco在Indonesia技术、欧洲制造和西非市场之间流动；
- Art Deco奢侈工艺与殖民展览；
- 电子和时尚产品的当代全球制造。

写作时按“原料—强制／劳动—运输—制造—营销—收藏／使用—废弃”追踪。形式相似性或图案名称不能单独证明殖民因果；Silverman等解释必须标明为学术论证并补档案。

## 十三　公共建筑、奥运会与国家形象

依用户规范，不以国徽、党徽、旗帜和地图构建国家形象。本书可转用：

- 1939纽约世界博览会企业未来馆；
- 1964东京奥运场馆、服务和pictogram；
- 2008北京奥运公共建筑与赛事基础设施；
- 2010上海世博中国馆；
- 2022北京冬奥公共建筑、技术系统和公共服务。

分析重点是委托制度、团队、建筑／服务、公众使用、城市后效、维护、无障碍、可持续和国际传播。赛事视觉中的国旗、国徽、政治标志不采用。

## 十四　从物件史到设计责任

第十四至十六章把社会责任分成：

| 责任对象 | 主要问题 |
|---|---|
| 使用者 | 安全、可用性、无障碍、隐私、知情 |
| 劳动者 | 工作条件、自动化替代、署名和技能 |
| 社会 | 住房、公共空间、迁移、偏见和信息操纵 |
| 环境 | 材料、能源、耐久、维修、循环和废弃 |
| 制度 | 企业治理、法规、标准、问责和多方参与 |
| 未来 | AI、自主产品、监控、disinformation和风险分配 |

Papanek、Nader、Schumacher、circular design、universal design、HCI和AI只提供不同历史节点。2023通史不能承担2026年的AI伦理现状。

## 十五　AI材料的证据边界

原书讨论AI／HCI、自主产品、Roomba、自动驾驶、监控、隐私、劳动替代、虚假信息和`uncanny valley`，态度审慎。它没有提出大模型让人获得“文明级理解力／创造力”，也没有系统覆盖生成式AI爆发后的研究。

第十六章应使用本书做历史连接：

```text
工业自动化
→ 人因与用户中心
→ 交互和服务设计
→ 数据化产品
→ AI、自主与治理
```

随后用2020—2026同行评议论文、标准、官方政策和事故／审计资料建立正文。未经作者、出处和原文核实的宏大能力判断删除。

## 十六　通史自身也要接受事实审计

book-0102已发现：

- d’Entrecolles年代错误；
- 1949年FRG／Soviet zone对应写反；
- Soviet Union解体写成1989；
- Walkman年代不一致；
- `Alexa`写成`Alexis`；
- Beijing Olympics索引一处写成1988；
- 若干China、GDP、forced labour、facial recognition、Foxconn和“first”强判断需另核。

这说明高质量综合通史也只能作为证据导航。教材引用路线必须是：

```text
book-0102发现主题
→ 本摘要定位章节／字符
→ 参考书目追到专题研究
→ 原始档案／政策／产品资料核实
→ 再写正文
```

## 十八　明确禁用与降级

- 不采用MUJI；
- 不采用地图／类地图、国旗、国徽、党徽和政治象征图；
- 不把2020年前后`today`更新为当前事实；
- 不以本书单独承担呼捷玛斯教育体系；
- 不以本书承担中国设计教育、行业组织、官方政策和院校清单；
- 不复制法西斯、纳粹、战争宣传或仇恨符号；
- 不把亚文化形式自动解释为进步立场；
- 不采用“大模型带来文明级理解力／创造力”等无出处判断；
- 不把综合通史的六个全球专题当作完整全球设计史。

## 十九　图像使用规则

575项图片在Markdown中全部缺失。图片出处可用来追权利人和馆藏，但不得据缺图编写视觉细节。补图需同时通过：

1. 正式馆藏或合法来源；
2. 完整作者、对象、日期、材料、尺寸和馆藏；
3. 权利／许可；
4. 与正文论点的直接关联；
5. 禁用符号、地图和政治敏感图像筛查；
6. 图像本身是否支持文字结论。

## book-0104补充：用专题论文拆解通史骨架

[book-0104](../summaries/book-0104.summary.md)不是另一部通史，而是对Raizman式长时段骨架的专题校验层。它用制图／教育、女性劳动、企业展览、汽车组织、CBS、铝业、应用艺术博物馆和国家经验等个案，提示通史中的每个“运动”都应拆成制度、劳动、媒介、使用和档案问题。Turner／Wang的中国与香港材料只作1989年前后文献史和追索入口；Sylvestrova只补战后AAB，不补呼捷玛斯；18篇文章须逐篇署名，不能以选集整体替代P0证据。

## book-0105补充：题名消歧与教材排除

[book-0105](../summaries/book-0105.summary.md)虽含`Issues of Design and Implementation`，其对象是存款保险制度，不是现代设计通史。它不应出现在任何教材章节的叙事、案例或参考文献中，只在书库处理层保留“语义误收”记录。该例证明自动关键词匹配必须经过对象、行动者、材料和学科问题四重核验。见[专题86](86_制度设计、政策移植与设计史的语义边界.md)。
## book-0106增量：2009年前后的制度／劳动截面

[book-0106](../summaries/book-0106.summary.md)不提供完整通史，而提供设计被政策化、服务化、系统化和可审计化的同期截面。其价值在于把公共政策、城市、公共艺术、博物馆、工作室、广告、研究、服务、电影和出版放入同一问题链；教材可据此把“形式变化”连接到采购、指标、软件、客户、劳动和机构。

去中心化限制也很清楚：英国居中心，其他欧美个案只是补充，中国仅以少量行业数字出现。全书不能充当全球代表或中国设计教育主证；应把它标明为特定时点、特定制度区域的批判文集，并用非欧美、劳动者、用户和较新材料扩展。

## book-0107增量：把价值创造史写回制度与使用

[book-0107](../summaries/book-0107.summary.md)不是设计通史，而是经济理论与设计实践的课程性综合。它可帮助通史把产品形式连接到价格、技术、企业、知识、政策、用户和价值观，并以双向立场转换避免把经济当背景或把设计当万能原因。

其德国、日本、美国和英国案例多为成功说明，全球与劳动维度有限；Heskett课程稿、Dilnot重构、Weber评论、Junginger延伸和未完成附录必须分层。中国政策、院校、企业与当代数字设计不由本书主证。参见[专题88](88_设计经济学、价值创造与组织能力.md)。
