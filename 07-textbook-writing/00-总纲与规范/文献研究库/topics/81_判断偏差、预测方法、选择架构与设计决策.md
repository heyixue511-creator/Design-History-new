# 判断偏差、预测方法、选择架构与设计决策

## 专题范围

本专题以[book-0099：Daniel Kahneman《Thinking, Fast and Slow》](../summaries/book-0099.summary.md)为核心，把判断与决策研究转化为设计史写作、设计研究、项目治理、风险传播和选择架构的证据检查表。该书不是设计史事实来源，也不是2026年人工智能研究；当前原文为2013年首译、2020年第三次印刷的印度尼西亚语译本，证据上限主要在2011年。

专题采用三层区分：

1. 可用于追踪行为决策研究史的概念、论文和学术争论；
2. 可作为设计研究与组织决策的待验证方法；
3. 因复制争议、伦理风险或年代差距而不能直接使用的案例。

## 一、双系统是解释性虚构，不是脑内零件

Kahneman用系统1概括快速、自动、联想性操作，用系统2概括费力、受注意控制的操作，并在导言与结论明确说两者是便于叙述的角色。设计教材可借此区分熟练反应、直觉判断和审慎检查，但不能：

- 把系统1／系统2画成两个固定脑区；
- 把用户分为“理性／非理性”两类；
- 把所有快速判断视为错误；
- 用“减少系统2负担”替代对任务、能力、学习和使用情境的分析。

专家直觉是否可靠取决于环境有无稳定规律，以及实践者能否得到长期、及时、清晰的反馈。训练时长本身不是充分条件。

## 二、设计史写作中的WYSIATI

WYSIATI意为判断者倾向根据眼前可见材料形成完整故事。与光环效应、叙事谬误、后见偏差和结果偏差结合后，设计史容易出现：

| 偏差 | 设计史中的表现 | 修正 |
|---|---|---|
| WYSIATI | 把博物馆藏品、企业档案或名家作品当作全部历史 | 主动登记缺席者、未保存对象和档案生产者 |
| 光环效应 | 由形式声誉推断组织、劳动和社会效果都成功 | 将形式、生产、使用和后果分证据链 |
| 叙事谬误 | 用一条连贯风格谱系覆盖偶然、冲突和失败 | 保留同时代替代方案和区域异步 |
| 后见偏差 | 因作品后来经典化，断言当时必然领先 | 恢复当时信息、风险和不确定性 |
| 结果偏差 | 用商业成功或获奖反推决策过程正确 | 分开过程质量与偶然结果 |
| 回归误读 | 把极端表现后的回落解释成制度或个人失败 | 查长期序列、对照和样本波动 |

这些概念只提供自审语言，不能替代原始档案和历史因果研究。

## 三、用户研究：从“生动故事”回到样本与基准率

### 1. 小样本不是小型总体

访谈、可用性测试和协议分析常用少量参与者。小样本可以发现机制和问题，却更易出现极端比例，不能由一次强烈案例推断人群频率。研究记录至少应说明：

- 参与者如何招募、谁没有进入样本；
- 任务、设备、环境和版本；
- 观察单位是人、任务、错误还是事件；
- 饱和、停止与排除规则；
- 结论是发现问题、估计频率还是比较方案。

### 2. 人物画像不能成为代表性刻板印象

Tom W.、Linda和职业判断实验说明“像某类人”会压过基准率。Persona若只追求生动、内部一致和可讲述性，会把刻板印象伪装成用户证据。应把人物角色分成：

1. 可回查的行为、目标和约束；
2. 样本内出现的模式；
3. 团队的假设与待验证项；
4. 不得推断的身份、人格和人口群体特征。

面孔“能力／可信度”研究不得用于招聘、风控、投票或用户分群。

### 3. 问题顺序、框架和分母

先问约会次数再问幸福感、以死亡率或生存率描述治疗、用“1/1000”或“0.1%”呈现风险，均可能改变回答。设计研究需保存问卷原词、顺序、展示格式和分母；不能只保存汇总数字。

### 4. 体验与回忆是不同资料

事后满意度可能主要反映峰值、结尾和故事，而非全部过程。服务研究宜组合：

- 实时或近实时体验记录；
- 任务持续时间、等待与中断；
- 事后整体评价；
- 再使用选择与长期记忆；
- 使用者目标、价值和实际后果。

不能为了制造“好结尾”而增加总痛苦或隐瞒过程问题。

## 四、预测与项目治理

### 内部视角与外部视角

内部视角根据项目计划、团队能力和当前进度讲述未来；外部视角从一组真正可比项目的结果分布开始。参照类别预测不是找一个著名案例类比，而是：

1. 明确项目类型、规模、技术成熟度和制度条件；
2. 建立有记录的参照类别；
3.统计完成时间、成本、失败、范围变化和维护；
4. 以分布形成基准预测；
5. 只有在有可验证项目特征时才调整。

### 计划谬误与竞争忽视

项目会遗漏未知困难，企业会只分析自己的方案而忽略竞争者同样行动。设计管理中的预算和路线图须保存最初估计、变更、取消和失败项目，不能只建立成功案例库。

### 独立判断与事前验尸

集体讨论前先独立记录估计，可降低顺序、权威和光环干扰。事前验尸要求假定计划已经失败，再让参与者独立写出原因。它的价值是合法化异议和扩大威胁搜索，不是预测所有失败。

### 决策过程与结果分开

项目成功可能来自运气，失败也可能发生在合理决策之后。决策档案应保存当时可获得的证据、备选项、估计、异议、批准理由和不确定性，而不是事后重写。

## 五、公式、算法与专家判断

Meehl、Dawes及简单评分规则说明，一致规则经常胜过不稳定的整体印象。对设计组织的合理推论是先结构化问题，而不是“算法永远优于人”：

```text
明确目标和损失
→ 独立采集相关维度
→ 检查数据质量、缺失和群体偏差
→ 使用透明基准规则
→ 允许有记录的例外
→ 监测分布变化、错误与申诉
```

任何高风险自动化都要回答：

- 预测目标是否等于应追求的社会目标；
- 训练／历史数据是否固化既有歧视；
- 谁承受假阳性、假阴性和无法分类的代价；
- 人是否有纠错、退出、解释和申诉渠道；
- 规则在环境变化后是否仍有效；
- “人工复核”是否只是形式背书。

本书早于深度学习与生成式大模型，不能支持模型理解力、创造力、主体性或“文明级”效果。

## 六、前景理论与选择架构

### 参照点与损失

人按相对参照点评价收益和损失，损失往往比等量收益更有心理重量。参照点可能来自现状、承诺、目标、同伴或界面默认值，因此设计者实际上参与规定何为“损失”。

“损失约为收益两倍”不是固定常数。对象是否日常交易、是否真实持有、经验水平、风险大小、贫困状态和实验程序都会改变效应。

### 框架与默认项

逻辑等价表述可引发不同选择；默认项又利用不行动、责任和后悔。选择架构若进入教材，必须附伦理条件：

1. 公共目的和受益者明确；
2. 表述不隐藏实质损失；
3. 默认项与退出同样清楚；
4. 退出成本低且可逆；
5. 分配后果和脆弱群体影响经过检查；
6. 有申诉、审计和版本记录。

器官捐献与养老金自动加入是特定政策案例，不能推导出所有默认操控均正当。

### 四重模式与风险传播

高概率收益、低概率收益、高概率损失、低概率损失会产生不同风险偏好。罕见事件又可能因生动描述被过度加权，或因经验中从未出现而被忽略。因此风险界面不能只追求“引起注意”，还须：

- 同时给出分子、分母和时间范围；
- 区分相对风险与绝对风险；
- 显示不确定性、数据缺口和比较基准；
- 避免用单个受害者图像替代总体信息；
- 对极低概率、高损失和不可逆事件给出场景与应对。

## 七、复制危机后的证据边界

本书出版时对若干研究表达很高信心。后续研究使下列内容不能作为稳定设计规律：

- 老年词、金钱、清洁、眼睛海报等社会／行为启动；
- 嘴含铅笔面部反馈的原始强效应；
- 自我损耗是有限生理资源及葡萄糖恢复机制；
- 法官因饥饿而系统改变假释决定的简单因果；
- 棉花糖任务直接预测成年成就；
- 篮球热手完全不存在；
- 收入达到固定金额后体验幸福不再增加。

教材若讨论这些例子，应把它们放入“一个研究范式怎样取得权威、又怎样被复制研究修正”的科学史，而不是改写成行为设计工具箱。
