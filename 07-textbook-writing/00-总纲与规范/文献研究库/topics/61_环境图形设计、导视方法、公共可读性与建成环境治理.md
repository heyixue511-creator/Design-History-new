# 专题范围

本专题研究20世纪后半叶以来标识与导视如何由建筑附属图形发展为连接空间认知、公共信息、机构识别、法规、制造和数字媒介的专业系统。当前主要入口是Chris Calori与David Vanden-Eynden于2015年出版的实践手册[book-0079](../summaries/book-0079.summary.md)。该书适合重建美国环境图形设计行动者的术语、流程和物质知识，不是独立通史、效果研究或现行法规指南。

核心问题不是“标牌长什么样”，而是：

```text
谁决定目的地、名称与信息层级
→ 空间如何支持或阻碍理解
→ 图形、语言与无障碍规则如何分配可读性
→ 设计如何经招标、制造、安装和维护成为公共物
→ 实体与数字系统如何长期更新
→ 谁承担材料、能源、劳动和废弃后果
```

# 核心结论

## 一、标识与导视必须区分

book-0079将`signage`理解为传递识别、方向、警告、规制、运营、纪念或解释信息的装置，将`wayfinding`理解为人在空间中感知、理解、决策和移动的过程。标牌只是导视的主动工具之一；入口、路径、视线、地标、光线、声音、工作人员和移动设备共同形成寻路条件。

这一界定纠正“迷路就加牌”的工程直觉。混乱的建筑组织、不可见入口、名称不一致和服务缺失不能仅靠增加标识修复。设计史因此应把导视写成建筑、图形、服务和制度的共同历史。

## 二、专业边界通过术语和起源叙事被建构

作者从`architectural signing／graphics`、`environmental graphic design`写到SEGD在2014年由Environmental改称Experiential，显示专业会随互动、数字和体验话语调整边界。然而，将洞穴图像称作环境图形设计并由此宣称它是最古老职业之一，是把现代专业投射到史前社会的正当化叙事。

正式教材区分三类证据：

- 专业行动者如何描述自身谱系；
- 协会、学校、期刊和事务所何时形成制度；
- 不同时期空间信息实践的具体历史。

三者不可合并为一条从洞穴直达当代事务所的连续进化线。

## 三、“标识金字塔”把信息治理放在造形之前

作者的`Signage Pyramid`包含信息内容、图形和硬件三系统。信息内容决定说什么、在何处说和消息之间的关系；图形决定字体、符号、色彩和版式；硬件决定三维形态、材料、安装和照明。信息被放在基础，却会受字符尺寸、建筑、预算、材料和法规反向约束。

这个模型的史学意义，是让“最终造形”不再吞没命名、分类、位置和物质实现。其效率与节约效果仍属作者经验，须用项目比较核验。

## 四、公共可读性同时是信息政治

命名一致、层级清楚、提前提示、确认信息和目的地识别能够帮助行动。与此同时，机构必须决定：

- 哪些地点值得被命名；
- 正式名称能否缩短；
- 信息按方向、字母、距离还是重要性排序；
- 哪些行为被警告或禁止；
- 谁以捐赠者或纪念对象被公开展示；
- 哪些语言和身体能力被设为默认。

因此，标识编程不是中性整理，而是在空间中分配可见性、通行权和组织权威。企业或公共机构的品牌系统也借建筑标识把自身秩序施加于场所。

## 五、标准化创造连续性，也可能抹平差异

统一标识类型、编号、信息表、字体、色彩、符号、构件和安装能支持批量制造、预算、替换和维护。`sign family`使不同功能在视觉上形成家族。过度标准化则可能忽略局部路线、语言社群、历史材料和使用者差异。

标准应被研究为协商结果，而非自动代表“优良设计”。每一套标准都需要追问适用范围、例外、申诉、维护和更新。

## 六、无障碍不能缩减为法规合格

book-0079分别讨论视觉字符、触觉字符、盲文、安装高度、对比、无眩光表面和突出物限制，说明同一信息需要多种感知路径。它主要依据2010年美国SAD及当时专业资料，并使用部分已经过时的残障语言。

教材应把法定最低要求、经验可读性、残障人士共同设计和公共服务公平分开。字符尺寸公式或安装数值只在核对当前官方标准后使用；不能以“通过规范”证明真实可用。

## 七、多语和符号不是无摩擦的“世界语言”

多语系统面对文字长度、阅读方向、语言顺序、字体供应、版面容量和政治优先级。符号可以节省空间，却会因文化、性别、年龄、经验和身体差异被不同理解。男性／女性卫生间符号依赖二元性别与服饰刻板印象；国际无障碍符号也存在静态身体与主动身体的争论。

book-0079提出的“三种以上语言会失效”和英语默认不作通则。正式写作应补语言服务政策、本地社群、跨文化理解实验、跨性别／非二元研究和残障共同设计。

## 八、设计过程是跨职业的责任链

本书把环境图形项目分为数据分析、方案、深化、文档、招标、制作安装观察和使用后评估。实际参与者包括：

```text
客户与审批者
→ 环境图形设计者
→ 建筑师、代码顾问、结构与电气工程师
→ 采购、总包与项目管理
→ 制造商、车间工人和安装者
→ IT、内容、翻译和培训
→ 清洁、维护、更新人员
→ 日常使用者与受影响社群
```

作者清楚区分设计意图图、制造工作图和工程责任，却仍以设计师为叙事中心。项目史必须恢复制造、安装、维护和使用者的共同作者地位。

## 九、使用后评估是证据链中的薄弱环节

book-0079对前期资料、图纸、规范、招标和送审写得细密，承认使用后评估常因客户不付费而依赖零散反馈。这使行业案例容易以完整照片、客户认可和视觉统一代替社会效果。

专题要求每个重要项目至少补：

- 任务完成率与错误路线；
- 到达时间和重复询问；
- 不同语言、年龄、身体与感官条件；
- 安全、拥堵与维护；
- 投诉、修改和停用；
- 长期材料与能源后果。

## 十、材料与数字媒介都应按生命周期研究

Naomi Pearson把环境影响分为原料、制造、制作／运输、使用／维护和废弃。复用既有构件、按标准板材尺寸设计、减少有毒黏合剂、采用可拆连接、就地制造、调光和长期耐久，需要联合判断。不存在脱离寿命、运输和回收条件的“天然绿色材料”。

数字标牌和交互终端也不是非物质替代品。屏幕依赖电力、数据、软件、网络、内容生产、散热、维修、更新和电子废弃。2015年有关App、Google Glass、室内定位和OLED的判断只能作为当时技术想象，不能当作2026年现状。

# 主要证据与使用层级

## P1：可直接作为行动者话语

- signage／wayfinding／interpretation／placemaking的专业定义。
- 七阶段设计过程及阶段回返。
- Signage Pyramid的三个系统。
- 标识类型、信息层级、位置和消息编程。
- 设计意图图、信息表、招标、送审、缺陷清单和使用后评估。
- 字体、符号、色彩、材料、安装、照明和数字显示的2015年实践知识。

## P2：必须外部互证

- SEGD、术语和专业形成史。
- AIGA／DOT、Hablamos Juntos、Clearview等系统的设计与效果。
- 典型项目的作者、成本、用户表现和长期维护。
- 环境材料、低VOC、回收和数字替代的实际影响。

## P0：定稿前必须核验

- 当前无障碍、交通、消防、建筑、分区和地方标识法规。
- 可能影响生命安全的字符、距离、对比、安装和照明数值。
- 图像许可与受限对象。

# 不采用或降级使用

- 洞穴图像是环境图形设计起点：只作职业起源修辞，不作通史事实。
- Paul Arthur“首创signage”、第一套正式方法等`first`判断：未核验前不采用。
- 三种以上语言必然失败、英语自然默认：不采用为普遍原则。
- 二元卫生间符号代表所有人：不采用。
- 法规数值与Clearview地位：未核对当前官方文本前不采用。
- 地图、位置图、`you are here`图和移动地图：按项目规范不用于教材图像。
- 项目图廊的完整照片：不能证明可用性、社会公平或环境绩效。

# 当前证据入口

[book-0079](../summaries/book-0079.summary.md)是2015年前后环境图形设计方法、职业边界和材料／数字实践的主要P1入口。凡历史首创、法规合规、可读性效果、用户表现、全球适用、环境绩效与当前技术状态，均须升级到协会档案、官方标准、项目档案、独立实验、使用后评估和环境数据后再进入教材定稿。

## book-0084增量：伦敦地铁图的制度、拓扑与使用

- [book-0084《Design Studies: A Reader》](../summaries/book-0084.summary.md)第72篇追踪Henry Beck 1931／1933方案、水平／垂直／45度线、色彩、符号、非地理比例、机构更新、版权和用户实践。
- “清晰”不是仅由形式自动产生：出版、网络变化、熟悉度、旅途情境和用户把拓扑与城市经验结合共同决定可用性。
- 该案例可补公共信息经典化、制度维护和用户研究，但不证明其他交通系统应复制同一语法；依教材规则不采用地铁图、地图或类地图图像。
- 时间、发行量、版权与用户效果须回Transport for London档案、原版图及独立研究。参见[专题66](66_设计研究、跨学科方法与设计物分析.md)。

## book-0086增量：页面层级不能代替空间可达

- [book-0086《Storytelling with Data》](../summaries/book-0086.summary.md)把伦敦地铁图和OXO作为可访问性／可供性示例，但主要讨论视觉简化与理解，没有处理空间法规、身体差异、现场失误、维护和公共责任。
- 其颜色、直接标签、层级和删减方法可用于导视图表的局部检查，不能证明系统可达；须由真实路径任务、残障参与、多语、安装条件和长期评估验证。
- 依项目规则不采用原书地图或类地图图像。参见[专题68](68_数据可视化、叙事修辞与商业决策传播.md)。

## book-0101增量：街名、霓虹与城市可读性

[book-0101](../summaries/book-0101.summary.md)把街道改名、商店橱窗、社会主义商品命名、1950年代“霓虹化”和1990年代巨幅广告视为城市可读性的政治／商业机制。霓虹既标示现代夜生活和实际方位，也可能在商品不足时制造超前的消费图像；广告既为历史建筑维护融资，也会占据视觉公共空间。因原文件72项图像全部缺失，教材不得据文本复原具体版式、色彩或导视效果。见[专题83](83_华沙战后重建、城市记忆、消费空间与公共生活.md)。
