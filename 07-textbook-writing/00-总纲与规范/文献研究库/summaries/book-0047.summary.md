# 本书的史学位置与核心问题

本书把交互设计史写成“人物—原型—组织—产品—使用者”连续发生关系的历史。它不只追踪装置外形，而是追踪鼠标、窗口、菜单、掌上设备、游戏、服务、网站、声音、有形界面和普适计算如何组织动作、感知、学习、协作与价值判断。作者的基本立场可概括为：

1. 交互不是软件完成后附加的界面，而是产品、服务与系统怎样表现、回应并被理解的设计对象。
2. 设计创新通常不是单一发明时刻，而由工程条件、概念模型、用户测试、快速原型、组织授权和市场采用反复耦合。
3. 设计应先理解人及其情境，再以尽可能早、频繁且低成本的原型暴露错误。
4. 交互设计依赖认知心理学、社会学、文化人类学、生态学、工程和商业协作；专业设计师不能单独占有全部知识。
5. 易用和效率不是唯一价值。游戏、声音、复杂愉悦、批判性对象与“替代的现在”把情感、歧义、文化和伦理带入交互设计。

这些观点来自作者本人及其职业网络，具有明确的硅谷、IDEO、Xerox PARC、Apple、MIT Media Lab、RCA和英语技术产业中心性。教材可用它重建交互设计内部如何叙述自身，但不能把采访记忆直接升级为“首创”证明，也不能把商业成功等同于普遍社会价值。

# 全书结构与详细摘要

## 第一章：鼠标与桌面——从增强人类智力到易学图形界面（字符1,152—92,629）

### 1. Engelbart、NLS与鼠标

作者以“为何是鼠标、为何是桌面”提出反事实问题，避免把今天熟悉的界面当作自然结果。Doug Engelbart回忆自己由正交滚轮测量装置想到二维定位；Bill English把设想制作成原型并参与设备比较。鼠标之所以稳定下来，不只因为有人提出概念，还因为指向／点击实验、屏幕任务和后续产品化使它相对其他输入装置取得优势。

Engelbart的目标不是让初学者立即舒适，而是“增强人类智力”。1962年《Augmenting Human Intellect》把能力系统分为人工制品、语言、方法与训练；NLS因此发展出文本定位、链接、协作和命令结构。1968年演示把鼠标、键盘、和弦键盘、屏幕编辑、链接与远程协作综合为可运行场景。作者将其称为改变世界的演示，但这一强判断须与演示档案、SRI／ARPA记录和同期系统史互证。

### 2. Stu Card与“支持设计的科学”

Stu Card以任务分析、近似计算、实验和Fitts定律说明科学模型如何缩小设计空间。重点不是用科学替代设计，而是让设计师能在大量候选装置中预测动作时间、准确率和学习成本。鼠标测试由此成为HCI把实验心理学连接到产品决策的范例。

### 3. Mott、Tesler与桌面隐喻

Tim Mott在文件出版情境中提出“办公室示意图”，其中桌面、文件柜、收发篮、打印机和废纸篓帮助非程序员理解电子文档。David Canfield Smith的Pygmalion把图像实体与程序数据／行为结合，Xerox Star再将其组织为办公图标。Alan Kay的纸张重叠比喻支持重叠窗口。

Mott与Larry Tesler使用`guided fantasy`：让编辑面对空白屏幕、键盘和鼠标，口述并共同想象未来编辑过程。参与式设计、空白屏实验和反复可用性测试由此进入Gypsy系统。Tesler坚持取消模式，推动插入点、拖曳选择、剪切／复制／粘贴、双击、光标反馈和单按钮鼠标。这里的“桌面”不是一人一次发明，而是PARC共同体、出版任务、图标语义、用户测试和Apple产品化的累积结果。

### 4. 证据边界

本章的优势是把鼠标、桌面、图标和编辑命令拆回多个参与者、多个原型和组织迁移；局限是大量关键节点来自事后采访。关于NLS、Alto、Star、Gypsy、Lisa及PARC“人才流失”的因果和优先权，均须原始论文、代码版本、专利、会议录像、项目档案及其他参与者证词互证。

## 第二章：个人计算机——GUI、鼠标工业设计与行为模型（字符92,630—197,470）

### 1. “低路”与“高路”

作者把电传终端／IBM PC兼容路线称为价格较低但界面有限的“低路”，把位图显示、鼠标和GUI路线称为“高路”。成本下降最终使后者进入大众市场。该二分有助于说明性能、价格和界面之间的历史张力，却容易把复杂产业竞争写成两条整齐路径；IBM、Microsoft、Apple、工作站、爱好者计算和软件生态须另作产业史。

### 2. Bill Atkinson、Lisa与Macintosh

Atkinson强调试错、用户测试和“先做界面”的工作方式。QuickDraw支持位图图形和重叠窗口；Lisa／Mac团队通过昼夜接力式原型与测试发展下拉菜单、对话框和窗口行为。MacPaint把算法能力转为可直接操作的绘画体验，HyperCard则以卡片、按钮和脚本成为80年代重要原型平台。

苹果鼠标的案例把界面史与工业设计、制造和成本连接起来。Hovey-Kelley团队在约25美元目标下处理球体、滚轮、按键、线缆、注塑、污染和寿命，说明“一个按钮”并非纯粹视觉简化，而是硬件、认知和产品策略的综合。

### 3. Microsoft鼠标与可测任务

Paul Bradley、Bill Verplank及其团队以点击、迷宫、精确定位、书写和键盘—鼠标换手五类任务比较原型；把滚球前移、外壳握持和制造结构一起迭代。“打磨块”提供形态启发，但最终设计不能还原为某一物件的形式类比。

### 4. Verplank的交互设计框架

Verplank用三个问题组织设计：`How do you do?`、`How do you feel?`、`How do you know?`，对应动作、反馈和概念模型。他把交互范式列为脑、工具、媒介、生命、交通工具与时尚，并以动机／意义／模式／映射四步组织项目。该框架适合作为20世纪末从业者教学模型，不是HCI统一理论。

### 5. Cordell Ratzlaff与Mac OS X

Ratzlaff叙述Apple在系统重构中让内容优先于界面杂物，以Dock、动画、列视图和时间维度重组桌面。团队强调在代码之前形成设计方向，同时仍需工程协作。作者对智能代理持审慎态度，认为代理若替人行动而缺乏可理解控制，会破坏直接操作。这一判断属于2004年前后的界面争论，不能直接替代当代AI代理研究。

## 第三章：从桌面到掌上——便携计算、笔输入与Palm（字符197,471—323,234）

### 1. Alan Kay与Dynabook

Alan Kay把计算机视为儿童可学习、可创造的新媒介，并借Bruner的动作性、图像性和符号性学习讨论界面。Dynabook不是后世平板电脑的完成蓝图，而是个人动态媒介的行动者愿景；NoteTaker等原型说明愿景受显示、电池、存储和重量约束。

### 2. GRiD Compass与GRiDpad

John Ellenby以“半个公文包”作为简报，推动约8磅、翻盖、平板显示、气泡存储、调制解调器和镁合金外壳的GRiD Compass。Sharp显示器供应、联邦快递60g冲击测试和高价专业市场共同塑造产品。1982年上市及“第一台笔记本”类说法须与Osborne、Epson、Dulmont等同时期设备按定义核验。

Jeff Hawkins把GRiDpad用于垂直行业，强调纸张的轻便、可标记和随手性仍难替代。Go、Newton、Momenta等笔计算项目显示手写识别、硬件成本、应用场景和市场时机之间的冲突。

### 3. PalmPilot与约束驱动

Palm团队把尺寸、299美元价格、同步和速度设为核心条件：设备必须能放入口袋、与PC交换数据、快速启动并避免等待与错误对话框。Graffiti不追求自然手写的完全识别，而让用户学习一套可靠字母。Rob Haitani所谓“Zen of Palm”以160×160像素、常用功能可见、少层级和实际测试形成克制的界面。

Palm V的金属、11毫米厚度、配件导轨及珠宝／时尚比喻，使掌上电脑从工具转向随身身份物。Dennis Boyle的叙述包含二元性别和时尚市场假设，只能作为当时营销话语，不能作为男女用户的自然差异。

Handspring的Springboard扩展槽、eyemodule相机和Treo把PDA、键盘、相机与电话逐步结合。融合不是单纯技术进步，还涉及无线网络、输入偏好、组织分拆和商业授权。

## 第四章：采用技术——从原型发明到消费者系统（字符323,235—447,276）

### 1. Liddle的三阶段

David Liddle把技术采用分为爱好者、专业者和消费者阶段。早期用户容忍复杂性以换取新能力，专业用户要求可靠生产力，消费者则要求可理解、愉悦、价格合理和整体服务。三阶段是经验性框架，不是所有技术必经的普遍定律，也不能覆盖公共部门、被迫采用、基础设施不平等和拒绝技术。

### 2. 汽车与数字摄影

作者把汽车视为成熟的复杂交互系统，说明控制标准、自动化、仪表和身体学习如何长期稳定。Mat Hunter与Jane Fulton Suri在Kodak项目中把数字摄影拆为准备拍摄、拍摄信息、创意控制、组织和展示五个部分，再以系统视角、情境脚本和体验原型连接相机、软件、显示与传输。模式转盘、胶片条浏览和捕捉／回看／发送结构不是孤立控件，而是交互架构。

### 3. Canon PhotoStitch与打印概念

Rikako Sakai以可用性测试修正工程师主导的PhotoStitch：用标签页、日常语言、图文结合和动画帮助替代术语密集流程。Canon的`Stitch Assist`案例说明软件与相机需要共同设计。

Epson概念项目邀请Naoto Fukasawa等设计师把打印重新放入家庭、记忆和摄影行为，形成抽屉、显影、交付等提案。它们是概念设计，不等于市场效果证据。

### 4. Kelley、Pixo、iPod与整合

David Kelley把交互设计解释为“让技术适合人”，并强调对象正在扩展为体验和服务。Stanford d.school、故事板、即兴表演和跨专业团队被描述为培养整合者的方式。

Paul Mercer的Pixo提供iPod软件基础，Apple再把硬件、滚轮、iTunes、内容和商店整合为系统。作者以此强调组织文化和软硬服务协同；不能据此把iPod成功归于单一设计师、单一公司能力或“天才产品”。

## 第五章：游戏——市场分类、玩具原型与生成系统（字符447,277—542,445）

### 1. Electronic Arts与游戏分类

Bing Gordon回忆Electronic Arts的创办、制作人制度、反复试玩及按兴趣、年龄、性别、形式、品牌、玩家数量和输入设备分类市场。分类体现2000年代游戏产业如何理解受众，其中关于男／女玩家、青少年和成年人兴趣的概括具有明显二元性别与本质化倾向。教材只能把它当作行业分类史料，不得改写为稳定心理事实。

### 2. Brendan Boyle的玩具方法

玩具与游戏团队大量头脑风暴，以低成本原型快速筛选，再让儿童试玩，最后向掌握渠道和品牌的公司授权。Aerobie Football、Finger Blaster和Fib Finder说明玩法、身体反馈、安全、制造与许可共同决定项目。商业成功率低，因此团队在早期并行生成许多方案。

### 3. Brenda Laurel与Purple Moon

Laurel通过观察、访谈和社会研究尝试理解青春期前女孩的叙事、友谊和游戏需求，发展Purple Moon的CD-ROM、网站、收藏物与社区。该项目有助于说明游戏业曾如何纠正男性用户默认值，但其“女孩／男孩”二分、性别信号和研究结论不能代表所有儿童；应由女性主义游戏研究、酷儿研究、阶级／种族差异及儿童数据伦理补充。原书含地图式研究呈现，依教材规则不采用图像。

### 4. Will Wright与《模拟人生》

Wright把游戏理解为模型、爱好和可供探索的系统，而非只有胜负的线性任务。SimCity、SimEarth、SimAnt和The Sims以规则、反馈层、失败、涌现与玩家自定目标形成“可能性空间”。Jay Forrester、James Lovelock和Christopher Alexander是其灵感来源，但游戏模型不能承担城市、生态或社会的真实因果证明。

## 第六章：服务——i-mode、服务生态与客户旅程（字符542,446—642,524）

### 1. 服务作为时间性设计对象

作者以电话和蜂窝服务说明：用户体验由终端、网络、资费、内容、客服、地点和时间共同形成。服务无形、跨触点并依赖组织，不能只用单一产品外形解释。

### 2. i-mode

Keiichi Enoki、Mari Matsunaga和Takeshi Natsuno的叙述把i-mode写成消费者导向的移动互联网服务。HTML兼容、手机专用按键／图标、内容组合、第三方开发者、计费和运营商价值链共同形成体验。内容被分为交易、信息、数据库和娱乐等类型。i-mode的成功数字、先后顺序及日本移动文化须由NTT DoCoMo档案、产业史和用户研究复核。

### 3. 失败的自动售货服务

联网可口可乐售货机的30分钟故障叙事说明，服务设计失败常不在按钮本身，而在网络、付款、库存、维护和异常恢复的依赖链。该故事适合教学“触点可见、后台不可见”的关系，不应泛化为所有联网售货系统。

### 4. Live|Work的八个方法概念

Live|Work提出：

1. `service design`：组织人与触点在时间中的整体体验；
2. `service ecology`：服务涉及的组织、关系与价值交换；
3. `touch-points`：人与服务发生接触的媒介、地点和人员；
4. `service envy`：从其他服务体验识别期望；
5. `evidencing`：把无形服务转为可见、可讨论的证据；
6. `experience prototyping`：模拟实际使用；
7. `service experience model`：综合触点与时间的可体验提案；
8. `service blueprinting`：连接前台、后台和流程。

团队以`rapido, piccolo, economico`强调快速、小型、经济的原型，并以“未来考古”伪造账单、广告、CCTV或服务痕迹来测试情境。伪造在设计内部用于明确模拟时可产生讨论；对公众传播时必须标识虚构，避免欺骗和伤害。

### 5. IDEO服务创新与Juniper在线银行

Fran Samalionis以同理研究、客户旅程和跨触点原型说明服务创新。Juniper项目通过观察、让参与者“画出自己的钱”及心理行为分类，形成`pathfinder／organizer／dreamer／onlooker`四类，并把系统重点放在不愿频繁管理财务的用户上，以仪表板、消息中心和免除某些逾期惩罚降低焦虑。该分类是项目模型，不是稳定人格量表；金融规则和业务结果须另证。

## 第七章：互联网——从直接操作到“到达某处”（字符642,525—747,973）

### 1. Winograd的三种交互隐喻

Terry Winograd区分命令式“对话”、桌面式“操作”和Web式“移动／到达”。Web的核心不只是页面图形，而是链接、位置、路径和即时反馈。普适计算又使计算能力分散到环境中。该叙述提供媒介范式比较，但“互联网”与“Web”及其技术史须保持区分。

### 2. Google

Larry Page与Sergey Brin叙述BackRub、PageRank、服务器基础设施、搜索质量、十条结果、摘要、速度和简洁首页。`Focus on the user`、`do one thing well`、`fast is better than slow`等“Google truths”是公司行动者原则，不是中性绩效结论。排名权力、广告、数据收集、劳动、平台垄断和后续业务不在本书覆盖范围。

### 3. BBCi

Steve Rogers把BBCi视为公共服务入口，讨论全局工具栏、搜索、可信编辑、受监管社区、主页迭代、地方化与个性化。源文件保存大量页面截图文字与地图／位置元素；教材可用文字说明公共服务门户和“数字包浆”，不使用地图图像，且需英国公共广播制度史、无障碍和受众材料补充。

### 4. Glass Engine

Mark Podlaseck为Philip Glass作品目录设计可视化浏览器，以属性条、中央游标、音频试听和直接操作让用户按时期、乐器、时长等关系漫游。用户测试帮助从复杂视觉方案收敛到单色界面。它是一个艺术家目录的实验案例，不能自动代表音乐检索的一般有效性。

## 第八章：多感官与多媒体——有形比特、声音和家庭物件（字符747,974—857,429）

### 1. 视觉、触觉与空间

“Visions of Japan”展览及IDEO项目室说明大尺度显示、空间记忆和外围感知如何超出桌面屏幕。展览体验具有策展和场所特定性，不能只由技术分辨率解释。

### 2. Ishii的Tangible Bits

Hiroshi Ishii区分GUI与TUI：有形表现既可作为控制，又与投影、声音等无形信息耦合。算盘、PingPong、musicBottles、Urp和Illuminating Clay显示实体、光影、模拟与计算可以共同承载信息。`tangible bits`是MIT Media Lab研究纲领和行动者概念，不是所有实体交互的唯一谱系。

### 3. Durrell Bishop：物应成为其自身

Bishop从厨房、Monopoly、金钱和智能答录机讨论物理令牌、指示物与可供性。他主张对象不必模仿屏幕按钮，可用材料、位置、发光、声音和幽默形成可记忆关系。朋友对象和LG墙面装置属于概念／企业研究，须区分原型、展示与商品化。

### 4. Joy Mountford：QuickTime、QuickTime VR与Bead Box

QuickTime团队以VideoWorks等原型展示“动态文档”，在控制器上比较播放、快进、倒退、拖动和拟人化“手控器”。用户研究显示多数参与者不喜欢脱离身体的手形控制，团队于是删去已经投入大量编程的方案。1991年QuickTime工具包说明原型、API、工程、内部倡导和用户评价共同形成产品。

“可导航电影”由Dan O’Sullivan的多张图像、Michael Chen的虚拟球及团队的内容演示组合，随后形成QuickTime VR。金门大桥和Pavlovsk Palace演示说明内容选择会决定新媒介是否被看见；关于优先权和项目成员须查Apple档案。相关全景／空间示意图不进入教材。

Interval的Bead Box用带电阻标记的珠子在网格中控制采样、密度和音高，并以灯光显示播放位置。不同年龄儿童和家长都表现兴趣，却使目标市场、渠道和定价更难确定。案例明确区分“研究中有吸引力”与“可持续商业”。

### 5. Bill Gaver：听觉图标、可供性与Equator

SonicFinder把点击、拖动、窗口、滚动和复制进度映射为材料、大小、摩擦与液体声音。Gaver强调听觉提供声源、内部结构、事件和情绪线索，与视觉呈现表面和空间信息不同；声音无法保持价值中立。

他回到J. J. Gibson的生态可供性，批评把可供性简化为“容易使用”或任意文化符号。可供性是身体能力、物理环境与可感知信息的关系；数字界面先作“物理环境”隐喻转换，才可借边界、移动和反馈让人探索。

Equator项目的History Tablecloth、Key Table和Drift Table把重量、时间、情绪猜测和远程影像融入家庭家具，追求舒缓、幽默和开放解释。Drift Table使用英国航拍位置图像；依教材规则不采用地图／类地图呈现，可用文字说明重量输入与缓慢漂移体验。

## 第九章：未来与“替代的现在”——复杂愉悦、简洁与普适计算（字符857,430—925,485）

### 1. Dunne与Raby

Dunne与Raby不以预测技术未来为目标，而以不同价值构造“替代的现在”。`technology as medium／product／critique`分别关注材料实验、产品进入系统及技术社会伦理的可争论化。`complicated pleasures`反对只把设计理解为消除摩擦，也允许矛盾、不可控、解释空间和心理叙事。

Placebo Project以八件家庭电子对象讨论人对不可见电磁场的想象。GPS Table在室内显示`lost`，Nipple Chair以振动表现传感结果；参与者形成远超设计师预期的故事。作者已承认样本自选、方法非科学和非正式民族志。教材不得借此证明电磁健康风险，也须讨论焦虑诱发、隐私、身体／性化呈现和研究伦理。

Energy Futures、Teddy Bear Blood Bag、排泄物能源、家庭氢生产、BioLand与Utility Pets以物件和场景把儿童劳动、动物／人体组织、能源与生物技术转为伦理冲突。这些提案是思想实验，不证明科学可行性、公众态度或制度优劣；儿童、动物、患者和身体伦理必须另补。

### 2. John Maeda

Maeda由Aesthetics & Computation Group转向Physical Language Workshop与`Simplicity`计划，希望以简单、免费、可扩展的软件和教育基础设施降低数字创作门槛。Design by Numbers以100×100灰度空间让视觉学习者通过绘图理解编程；Reactive Books与Maeda@Media则连接个人作者性、动态图形和出版。

他把计划类比为数字时代的Bauhaus，同时批评包豪斯工匠／艺术家政治关系。此处是2004年前后的设计教育愿景和行动者解释，不是包豪斯校史，也不能补充呼捷玛斯。所谓“简洁法则”在文件中由版面识别混乱，须回查正式版本。

### 3. Jun Rekimoto

Sony Interaction Laboratory通过ActiveInk、BlockJam、TouchEngine、Time-Machine Computing、NaviCam、Pick-and-Drop、手势和传感环境探索屏幕外交互。Pick-and-Drop让触笔从一台设备“拾取”对象再放到另一台设备，将剪切／粘贴转为跨设备直接操作。

Rekimoto预期移动设备、位置感知、近距离安全建立和环境显示结合。Stu Card提醒手势需要记忆，最好限制在少量、模拟性而非任意符号的集合。2004年前后的普适计算预测须按历史语境阅读；定位监控、同意、数据安全和平台权力在原书中不足。

## 第十章：人与原型——作者的方法总结（字符925,486—1,067,211）

### 1. 设计、约束与默会知识

Moggridge借Charles Eames把设计定义为为特定目的安排要素的计划，并把识别约束、问题框定、产生替代、选择与原型化列为核心技能。设计依赖大量难以完全语言化的默会综合，因此工作室教育以项目、批评和做中学为中心。

作者按复杂性把人因知识排列为人体测量、人体生理、认知心理、社会学、文化人类学与生态学，分别连接物体、人机系统、计算机交互、连接系统、全球设计和可持续设计。这个层级是从业者框架，存在把学科、身体和文化整齐阶梯化的风险；“性别、族裔人体尺寸”等历史分类也须由当代包容性设计与残障研究修正。

作者给出交互设计的窄义与广义：窄义是数字且互动之物的主观和质性方面；广义是所有数字且互动之物的设计。窄义强调设计专业，广义纳入HCI、计算机科学、工程、心理学、社会学和人类学。

### 2. 研究潜在需求

Jane Fulton Suri把观察从安全评估前移到设计开始阶段。IDEO的51张方法卡分为`Learn／Look／Ask／Try`：

- Learn：流程分析、认知任务分析、历史分析、亲和图；
- Look：墙上苍蝇、一日生活、跟随、个人物品清单；
- Ask：概念关系呈现、拼贴、跨国通讯员、卡片分类；
- Try：同理工具、情境脚本、未来标题和信息表演。

这些方法旨在比较“人实际做什么”与“人说自己做什么”，并寻找尚不能直接陈述的需求。它们是方法菜单，不是每种项目都适用；研究者必须处理抽样、知情同意、隐私、解释权、补偿和研究结论被商业组织如何使用。源书的`conceptual landscape`等地图／图绘方法可作研究史文字说明，但教材不使用地图结果。

作者强调极端使用者而非平均值，并以ATM超时说明按平均值设计会排除一半较慢用户。该例仅说明分布思维，具体阈值须用真实数据、无障碍与任务风险决定。

### 3. 体验原型

作者以Gossamer Condor和Lisa团队的“每日原型”说明快速迭代；把原型定义为最终方案出现前的设计表征。Buchenau与Fulton Suri把体验原型分为：

1. 理解既有经验与情境；
2. 探索、评价设计概念；
3. 向同事、客户或使用者沟通主观价值。

ROV驾驶游戏、guided fantasy、“画出你的钱”、儿童图片通信器、滚动条、HyperCard、鼠标任务、服务证据、Kiss Communicator、Engelbart演示、玩具、QuickTime和Pick-and-Drop分别说明不同目的需要不同真实度。原型不是越逼真越好，而是以最低成本回答当前最大不确定性。

### 4. 原型技术与专业协作

Duane Bray把交互设计分为屏幕体验、交互产品和服务。纸张、便利贴和情境卡用于早期结构；Director、Dreamweaver、Flash等用于像素、动画和行为；Basic Stamp、传感器、泡沫模型与现成物件用于交互产品；真实数据、服务器和跨触点演练用于服务。

`live prototyping`让原型直接连接数据库、网络和真实内容，缩短设计与实现之间的翻译。AT&T Wireless mMode与Philips Streamium说明规模、内容数量和网络现实会暴露静态演示无法显示的问题。工具材料截至2004年前后，不能作为当前原型软件清单。

作者认为极限编程中的结对、频繁构建、客户代表和迭代验证与人本设计趋同。开放、灵活、可移动的工作空间可支持协作，但空间本身不能消除组织权力、角色冲突或劳动压力。

### 5. 新事物、新版本与十个过程要素

对无先例项目，应由潜在需求、广泛约束和粗糙原型快速开始；对既有产品的新版本，应先系统掌握`state of the art`，避免重复已有错误。两者都需不断回到使用者和评价。

末尾把过程概括为约束、综合、框定、构思、构想、疑问、选择、可视化、原型和评价十个要素。它们常循环出现，却不像流程图那样固定有序，更接近弹珠机式跳转。评价应尽早、频繁并延续到尽可能晚，但安全关键系统仍需正式验证、可追责门槛和独立监督，不能只依赖直觉迭代。

# 核心概念与教材表述边界

| 概念 | 本书中的含义 | 教材使用边界 |
|---|---|---|
| Interaction design／交互设计 | 设计数字产品、服务和系统的行为、反馈、概念模型及主观质性经验 | 术语形成不是Moggridge一人完成；须补IxD、HCI、软件设计和教育制度史 |
| Direct manipulation／直接操作 | 通过指向、选择、拖动与即时反馈直接作用于可见对象 | 不是无中介，也不自动保证可访问、透明或民主 |
| Desktop metaphor／桌面隐喻 | 以办公室对象帮助人理解电子文档、容器和动作 | 由多位参与者和多个系统稳定；不是自然或普遍文化模型 |
| Guided fantasy／引导式想象 | 使用者面对未完成／空白界面，与研究者共同口述未来任务 | 接近参与式方法但设计权仍不必然平等；需报告参与者与分析过程 |
| Participatory design／参与式设计 | 本书主要指让潜在使用者参与界面想象和测试 | 不能以Mott／Tesler案例代替斯堪的纳维亚劳动民主传统 |
| Interaction architecture／交互架构 | 跨设备、模式、信息与任务组织整体体验的结构 | 是Kodak案例中的从业者概念，绩效须由项目结果和用户数据互证 |
| Experience prototype／体验原型 | 为理解、探索或沟通人将如何经历产品、空间或系统而制作的表征 | 不是成品替代物；研究有效性取决于问题、情境、样本和偏差 |
| Service ecology／服务生态 | 服务中的组织、参与者、媒介、价值和依赖关系 | “生态”是组织关系比喻，不等同自然生态影响 |
| Touchpoint／触点 | 人与服务接触的人员、空间、物件、界面和传播媒介 | 不应只优化前台；须连接后台劳动、数据和异常处理 |
| Evidencing／服务证据化 | 用账单、广告、通知、空间痕迹等使无形服务可见 | 明确设计模拟与欺骗边界；公共传播须标识虚构 |
| Tangible bits／有形比特 | 以实体表征／控制数字信息，并与投影、声音等耦合 | 是Ishii研究纲领，不覆盖全部实体交互史 |
| Auditory icon／听觉图标 | 用现实事件／材料声映射数字对象与操作 | 映射含文化和情绪，不存在完全中性声音 |
| Affordance／可供性 | 身体、环境物理条件与可感知行动信息之间的关系 | 不等于“按钮看起来能点”；须区分Gibson、Norman及文化学习 |
| Alternative nows／替代的现在 | 用不同价值构造与当前现实并列的设计提案 | 不是技术预测；伦理争论和社会影响须另证 |
| Complicated pleasure／复杂愉悦 | 允许矛盾、歧义、不可控和想象参与的产品经验 | 不能成为伤害、排斥、误导或不可访问的免责理由 |
| Ubiquitous computing／普适计算 | 计算分散于移动设备、物件、空间和传感环境 | 须补监控、隐私、网络安全、劳动及环境成本 |
| Live prototyping／实境／在线原型 | 让原型连接真实代码、网络、数据库或内容 | 真实度提高也增加数据、隐私、安全和误投产风险 |
| Tacit knowledge／默会知识 | 设计师／团队难以完全语言化的综合判断 | 不能用来回避证据、说明、伦理审查和可追责决策 |

# 写作方式与史料组织方法

本书可为《现当代设计史》的数字设计部分提供一种“从熟悉动作回问历史”的组织方法：

1. 先从当下习以为常的动作提出问题，如“为何是鼠标”“为何是桌面”。
2. 再把稳定对象拆为人物回忆、原型、测试、工程、组织与市场采用。
3. 以受访者长段第一人称呈现行动者判断，由作者在前后建立因果连接。
4. 在章末把个案上升为方法概念，并在第十章回收为总体流程。
5. 让成功与失败原型并置：手控器被删、Bead Box未商业化、售货机故障和笔计算失败都参与解释。

教材吸收这一方式时需要增加三项约束：

- 不让口述史承担未经核验的“第一／唯一／决定性”结论；
- 不把作者职业网络之外的劳动者、使用者、地区和制度变成背景；
- 在技术对象之外追踪专利、资本、供应链、标准、平台、数据、环境和权利。

# 作者立场、证据局限与不采用项

## 作者立场

- 明确支持以人为本、跨学科、快速原型和持续评价。
- 倾向把交互设计发展写成从研究原型到成功商业产品的创新谱系。
- 以设计师和技术领袖的创造性判断为叙事中心，同时承认团队、使用者和失败的重要性。
- 对复杂愉悦、批判性设计和文化实验保持开放，但总体仍以专业设计推动改进为基调。

## 主要局限

1. 口述记忆偏差：采访多发生在事件后十年至数十年，成功者更容易进入叙事。
2. 地域与机构中心：美国西海岸、英国RCA、MIT、Sony与大型公司占主导；中国、苏联／俄罗斯、拉美、非洲、南亚和东南亚数字设计史不足。
3. 劳动与供应链不足：程序员、测试员、工厂工人、客服、内容审核、采矿、组装与电子废弃物大多不可见。
4. 性别与分类问题：Palm V、游戏市场和Purple Moon多处沿用二元性别和时代刻板分类；女性受访者虽有重要位置，制度性不平等未被系统分析。
5. 种族、阶级、残障与殖民不足：多数“用户”属于可进入消费技术与设计研究的群体；无障碍、全球不平等和殖民基础设施不是主轴。
6. 商业成功偏差：Apple、Palm、Google、i-mode和iPod等成功案例占比高，失败、维护、监管和抵制历史不足。
7. 时间边界：材料多截止2004年前后，不覆盖智能手机平台成熟、社交媒体、云计算、设计系统、算法平台、生成式AI及其治理。
