# PROJECT_CONTEXT

## 书库研究范围

本知识库服务于《现当代设计史》（设计学理论专业）教材的文献分章、证据核验和写作。原始书籍位于仓库根目录 `00-book/`，保持不改；本目录只保存摘要、跨书专题、索引和机器可读处理记录。

当前书籍层共登记 517 个 Markdown 文件，总字符数 343,504,294。已经全文读完 103 个，正在读取 0 个，待读 414 个；已审计读取 71,106,551 字符。原始论文目录 `00-paper/` 也纳入全文读取范围；书籍报告、论文报告和增强报告不再逐文件全文读取，只作按需辅助索引。

## 四层检索结构

1. `PROJECT_CONTEXT.md`：判断研究领域、处理进度、主要冲突和研究空白。
2. `topics/`：汇总跨书专题，区分主要证据、交叉参照、争议与不采用材料。
3. `summaries/`：每本书一份结构化摘要，保存版本性质、章节结构、观点、人物机构、历史事件、可引用证据及局限。
4. `../../../00-book/`：回查原始 Markdown，核对章题、字符范围、图版、原文措辞和上下文。

辅助索引包括：

- `BOOK_INDEX.md`：面向人工查看的书籍编号、题名、作者、年代、主题、读取状态和摘要链接。
- `BOOK_MANIFEST.jsonl`：面向程序的稳定编号、相对路径、哈希、字符数、读取进度和摘要状态。
- `GLOSSARY.md`：人物、机构、流派和术语的跨书对照。
- `TIMELINE.md`：经过跨书核验的重要年代、事件、作品、机构沿革和政策节点。

专题文件和单书摘要只是导航、判断与证据管理层，不能替代原文。教材正文中的明确事实、引文和强判断，最终都必须回到原始 Markdown 或更高等级的一手材料。

## 引用与匹配规则

- 不以文件名、题名、搜索命中或既有报告直接决定教材章节。
- 区分作者观点、编者意见、历史行动者原文、图注、索引和后世评论。
- 教材中的事实性结论必须能够回到章／节标题、连续字符范围、图版号或其他明确锚点。
- 摘录只保留支持结论所必需的短句，并同时记录其前后文所限定的语义范围。
- “第一”“首次”“唯一”“开创”“彻底改变”等强判断必须用独立材料交叉核验。
- 中国、殖民、种族、性别、政治宣传和亚文化材料必须核查作者立场与表述时代，不能用形式评价替代历史立场。
- 设计方法类著作中的规范性主张，不直接改写为已经发生的历史事实；历史叙述与作者建议应分别登记。
- 每项文献匹配最终标为“主要使用”“交叉参照”“批判性史学材料”或“不采用”，并说明原因。
- 哈希变化时只重读对应原文，并更新其摘要、相关专题、索引和本文件；不得无依据沿用旧摘要。

## 更新原则

每完成一部书或一篇论文的连续全文读取与哈希核验，即在同一处理批次内同步更新单书／单篇摘要、相关专题、`GLOSSARY.md`、`TIMELINE.md`、本文件及教材章节候选关系。若某一层没有新增，须在来源摘要中说明，而不是留作未经判断的空白。全库读完后进行的是交叉核验、消歧、去重、补缺和正式定稿。

`00-paper/` 已建立独立的论文摘要清单和来源类型字段，并接入后续专题与教材章节证据网络。三类报告目录不做逐文件全文读取；其中的概括只能作为检索提示，不能覆盖原书或原论文的证据等级。
