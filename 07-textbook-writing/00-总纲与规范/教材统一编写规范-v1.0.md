# 《现当代设计史》教材统一编写规范 v1.0

> 适用范围：导论、五编十六章、结语及全部教学栏目
> 适用对象：设计学理论专业本科高年级与硕士基础课程
> 状态：第一版；在第四章样章审校后修订为 v1.1

## 一、编写目标

本教材以“人工世界如何被生产、使用、解释和治理”为总问题。正文不以大师、名作和风格更替为唯一主线，而以物、劳动、制度、流通、使用、权力和环境后果的关系为解释单位。

每章必须同时完成四项任务：

1. 提供清楚的时间坐标；
2. 提出并回答一个可论证的历史问题；
3. 示范一种设计史研究方法；
4. 把历史判断连接到设计学理论问题。

## 二、章节规格

- 每章建议 1.4—1.8 万字；
- 设置 5—7 个正文小节；小节内部用三级标题组织论证，不用增加同级小节制造目录密度；
- 使用 8—12 幅具有证据功能的图像；
- 核心案例 4—6 个，其中至少一个普通／匿名案例、一个反例和一个跨区域转译案例；
- 核心文献 8—12 种，延伸文献 10—20 种；
- 每章设 4—6 个关键词、3—5 个思考题和一个史料练习。

## 三、统一章法

1. **开篇历史现场**：用一件物、一次展览、一份制度文件或一个使用场景提出矛盾。
2. **承上与设问**：说明上一章的解释为何不足，本章为何必须转换尺度。
3. **概念与史料**：界定核心术语，交代史料类型、保存偏差和作者立场。
4. **历史叙事主体**：按“对象—行动者—制度—观念—后果”展开。
5. **对象细读**：将材料、形式、结构和观看／使用经验与历史机制连接。
6. **反例与争议**：呈现至少一种竞争性解释，并说明各自证据边界。
7. **跨区域关系**：处理真实的人员、图样、制度或物品流动，不添加装饰性的“全球视角”。
8. **章末结论**：依次回答“解释了什么—边界是什么—还剩什么问题—为何进入下一章”。
9. **教学组件**：关键词、时间轴、史料实验室、思考题和延伸阅读。

## 四、论证与段落

正文段落优先采用：

> 初步判断 → 可核验材料 → 对象／形式／使用分析 → 机制解释 → 反例或限定 → 条件性结论

一个段落只承担一个主要判断。段首句提出判断，段末句说明该判断对本节问题的作用。避免以人物生平、作品清单或连续引文代替论证。

### 史料与学术观点的组织方式

正文吸收仓库“写作参考体例”的三种方法：用彼得·伯克《欧洲近代早期的大众文化》的方式先检查概念和材料的生产条件；用《意大利文艺复兴》的方式把作品扩展到生产者、委托者、用途和制度；用《艺术与观念》的方式把形式描述组织为可跟随的观看路径。三种方法合用时，必须在观念阐释之后补入来源检查、反例和适用范围，不能把强叙事误写成必然因果。

引入一份历史文献时，依次处理：

1. **文献身份**：作者／机构、形成时间、文献类型、发表或使用场合；
2. **发言位置**：文献面向谁、试图解决什么问题、具有何种修辞或制度目的；
3. **观点转述**：先准确说明文献提出了什么，再解释其关键词，不以教材作者的概念替换历史术语；
4. **证据权限**：说明该文献能够证明行动者的主张、制度目标或公共形象中的哪一项，不能证明什么；
5. **交叉核验**：与课程表、产品、账目、图像、通信、使用记录或其他研究对照；
6. **论点回收**：末句说明该材料如何修正本段判断，并把尚未解释的问题交给下一段。

学术观点不按“某某认为”的名单式方式堆叠。每次引入研究者观点，都要说明该观点针对何种问题、依赖何种材料、提供了哪一种解释以及解释边界。两种观点并置时，比较它们选择的证据和解释变量，而不只比较结论是否相同。

句际关系必须可辨认：

- 从事实进入解释时，用“这表明”“由此可见”的前提必须在前句中真实出现；
- 从行动者自述转向历史判断时，明确使用“宣言声称”“课程文件规定”“实际记录显示”等不同主语；
- 转折用于修正判断，让步用于保留有效部分，递进用于扩大解释尺度，因果词只用于已有中介机制的关系；
- “这种”“这一”“它”等承接词必须有唯一、清楚的前项，避免抽象指代悬空；
- 段末不重复段首，而应给出限定结论，并说明下一段为何需要更换材料或尺度。

正文应始终区分三种声音：历史行动者的主张、研究者的解释、教材作者基于证据作出的判断。直接引文用于保留关键措辞；一般观点优先准确转述；教材作者的进一步推论必须标明依据和条件。

### 禁止性写法

- 用“时代精神”直接解释所有形式；
- 把风格相似自动写成历史影响；
- 把设计师宣言等同于实际生产和使用；
- 用单件名作代表一个国家或时期；
- 将今天的“设计师”职业边界投射到历史；
- 无证据使用“首次、完全、必然、普遍、决定了”等绝对表述；
- 把中国或其他非欧美地区放在章末作为影响附录。

## 五、证据分级

| 等级 | 含义 | 正文用途 |
|---|---|---|
| A | 已回查合法取得的原版或可靠影印本，版本、页码和上下文明确 | 可支撑核心判断和短引文 |
| B | 项目源文本可回查，报告锚点匹配，但尚未核定原版页码 | 可用于初稿转述；定稿前升为A |
| C | 深度报告或增强报告提供线索，支持关系尚未人工复核 | 只能用于检索、提问和材料规划 |
| D | 展览网页、企业材料、新闻、一般网络资料 | 仅作线索或说明当代接受史 |

核心论点至少需要两个相互独立的来源，其中至少一个在定稿前达到 A 级。报告中的全文百分比只用于回查，不作为出版引注。

## 六、引注与书目

1. 初稿采用脚注制，记录作者、题名、版本、出版地、出版社、年份和页码。
2. 转引必须标明原始作者与实际阅读来源，不伪装成直接阅读。
3. 译文由编写者翻译时标注“笔者译”；已有权威中译本时核对术语。
4. 引用一手宣言时同步说明文本发表场合、受众与修辞目的。
5. 项目文件编号写入工作包证据表，不进入出版正文。
6. 参考文献分为一级史料、核心研究、比较研究和延伸阅读。

## 七、概念、译名与年代

- 首次出现使用“中文名（原文名）”，后文使用统一中文名；
- 人名、机构名、运动名和课程名统一进入全书术语表；
- “现代性、现代化、现代主义、功能、标准化、理性化”等词必须结合当时语境解释；
- 年代不确定时使用“约”“不晚于”或时间范围；
- 设计、工艺美术、图案、商业美术等历史术语不得互相替换；
- 引用OCR文本时必须核对人名、年份、断词和特殊字符。

## 八、对象和图像分析

每个核心对象至少回答：

1. 谁提出、制作、委托、销售、使用和维护？
2. 使用何种材料、工具、工艺与能源？
3. 形式如何组织观看、身体和行动？
4. 通过何种制度、媒介和市场传播？
5. 谁从中获益，谁被排除，成本由谁承担？
6. 后来的收藏、展览和出版如何改变其意义？

图像不是装饰。每幅图应在正文中被分析，并记录来源、权利状态、许可范围和替代方案。项目OCR图片占位不能直接用于出版。

## 九、中国与全球关系

- 以可证实的人员迁移、学校课程、译本、展览、企业合作、图样和物品流动建立关系；
- 区分直接接触、间接传播、平行发展、后设归类和后来的正典化；
- 不以“受西方影响”结束解释，应追问地方选择、误读、制度限制和再创造；
- 同一章内尽量使用相同指标比较不同地区，避免只比较形式表面。

## 十、教学语言

正文面向具有设计基础但尚未接受系统史学训练的学生：

- 首次出现的史学方法用一句话解释；
- 每节先给问题，再给材料与分析；
- 专业术语准确但不堆叠；
- 关键争议允许保留开放结论；
- 教学提示与正文区分，不用课堂口语替代学术表达。

## 十一、工作流与版本

```text
总纲冻结
→ 章节工作包
→ 证据回查
→ 章节初稿
→ 图像与版权核验
→ 事实审校
→ 同行评阅
→ 课程试用
→ 全书统稿
→ 出版交付
```

章节工作包未达到以下条件不得进入正文：

- 核心问题和章际功能明确；
- 三级提纲与字数分配完成；
- 核心论点有证据路线；
- 案例具有不同论证功能；
- 明确列出材料缺口和不可写结论。

## 十二、成稿验收

1. 主要判断是否有可回查证据？
2. 是否区分意图、制度宣传、实际生产和使用经验？
3. 是否完成对象细读，而不只描述外观？
4. 是否解释制度和因果机制？
5. 是否处理反例、地区差异和解释边界？
6. 是否避免欧美时间替代全球时间？
7. 中国内容是否进入因果链？
8. 是否看见匿名劳动、性别、身体差异和环境成本？
9. 图像是否承担证据功能并完成权利登记？
10. 章末是否真正导向下一章？
