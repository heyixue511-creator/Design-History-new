# Richard Buchanan、Victor Margolin 编：《Discovering Design》增强报告

## 一、源报告映射与增强定位

- 源书：`00-book/Buchanan, Richard; Margolin, Victor (eds.), Discovering Design, 1995.md`
- 源报告：`01-book-report/0503 - Discovering Design（1995）.深度报告.md`
- 文献性质：设计研究形成期论文集 / Design Studies Anthology
- 增强目标：在源报告对后工业转型、服务与信息设计、社会责任、设计史和女性主义批评的分析基础上，进一步说明“发现设计”这一方法如何建立开放但负责任的设计研究共同体。

本书采用“发现设计”而不是“定义设计”的策略。它不从固定职业清单出发，而是观察设计活动在技术、服务、传播、教育、历史、性别和社会问题中如何显现。

## 二、理论定位：为什么是“发现”而不是“定义”

固定定义通常采用以下方式：

```text
设计 = 某种职业
设计 = 某类产品
设计 = 某套形式能力
```

这种定义在工业生产相对稳定时具有分类作用，但面对服务经济、信息系统和社会组织问题会迅速失效。本书提出的替代路径是：

```text
具体问题情境
→ 有意识的计划与构形活动
→ 多方知识和价值冲突
→ 实践判断
→ 人工情境及其后果
```

“发现”并不意味着设计无边界，而意味着边界必须在具体问题、行动者、能力和责任中被论证。

## 三、后工业转型与设计对象扩展

制造业中心的设计通常把对象理解为可批量生产的实体产品。后工业与信息社会使设计进入：

- 服务流程；
- 组织沟通；
- 信息架构；
- 交互规则；
- 教育与公共服务；
- 社会系统；
- 技术文化和符号传播。

这一扩展改变了设计成果的形态。成果不再总是封闭成品，而可能是规则、流程、界面、组织关系或持续调整的服务。

因此，设计师不再能够独立控制全部问题，需要与工程、社会科学、人文研究、管理、公共机构和使用者协作。

## 四、开放性与专业责任的张力

对象扩展带来一个核心矛盾：

```text
过窄的专业定义
→ 设计退化为产品形式和市场包装

无限扩张的设计定义
→ 一切计划活动都可被称为设计，专业责任消失
```

本书的解决方向不是回到封闭专业，而是用实践判断维持边界。研究者需要说明：

1. 该活动改变了什么人工情境；
2. 使用了哪些专门知识；
3. 谁参与决策；
4. 谁受到影响；
5. 设计者需要对哪些后果负责。

## 五、设计研究的共同问题

设计研究不必拥有统一方法，但可以由共同问题组织：

```text
做什么？
为谁做？
谁定义问题？
谁拥有知识和决策权？
技术可能性服务何种社会目的？
结果形成什么样的世界？
```

这些问题连接历史、修辞、技术、符号、社会责任和性别研究，使设计研究成为交流网络而非强制统一的学科体系。

## 六、技术不是目的，而是行动条件

本书反对两种技术观：

- 技术决定论：新技术自然带来社会进步；
- 工具中立论：技术只是一种手段，与价值无关。

设计研究应追踪：

```text
技术能力
→ 组织采用方式
→ 设计规则和界面
→ 使用者行动机会
→ 社会与文化后果
```

自动化、信息系统和服务技术既可能扩大参与，也可能强化管理、监控和专业控制。关键在于技术被何种制度目标和价值判断组织。

## 七、消费者与使用者的区分

当设计主要服务大众消费时，人的角色容易被压缩为购买者。消费者关注市场交换，使用者则涉及：

- 实际需要；
- 身体与认知能力；
- 长期使用；
- 维护与修理；
- 公共服务权利；
- 非市场生活情境。

设计的社会责任要求从“如何刺激选择”转向“人如何在人工环境中生活与行动”。教育、残障、全球南方和公共服务问题因此不是专业边缘，而是检验设计价值的核心场域。

## 八、设计史作为实践的批判资源

设计史在本书中不是形式库存，而具有三项作用：

1. 揭示专业边界如何形成；
2. 说明技术与市场假设并非自然；
3. 为当代实践提供反思距离。

现代主义崩解后，设计缺乏统一哲学并不意味着历史失去作用。恰恰相反，历史能够显示各种“理所当然”的方法、职业和价值标准具有特定制度来源。

## 九、性别、工艺与学科排除

女性主义设计史证明，设计的固定职业定义曾系统排除：

- 女性工艺劳动；
- 家庭生产；
- 装饰和纺织；
- 非正式协作；
- 消费者和使用者的创造性行动。

因此，扩展对象不仅是材料增加，也是对知识权力的修正。研究者需要检查“设计师”“专业”“工业产品”和“创新”等概念如何分配历史可见性。

## 十、与其他核心节点的连接

### 与 `0504 The Idea of Design`

`0503` 侧重设计研究如何通过问题领域被发现；`0504` 更集中于设计观念、实践推理、人工物意义和伦理条件。

### 与 `0508 Design History or Design Studies`

Margolin 后续明确讨论设计史与设计研究的学科边界。`0503` 已经以多作者实践展示开放研究共同体的可能形式。

### 与 `0505 Design Studies: A Reader`

`0503` 记录1990年代设计研究形成期；`0505` 显示全球化、性别、消费与政治经济如何成为成熟议题。

### 与 `0514 Routledge Companion to Design Studies`

`0514` 将早期探索制度化为服务、社会、参与、数字制作与行动主义等成熟分支。

## 十一、《现当代设计史》研究框架

研究某个设计转型时，可依次回答：

1. 传统专业如何定义对象？
2. 哪些新技术或社会条件使定义失效？
3. 新对象需要哪些跨学科知识？
4. 哪些群体被旧定义排除？
5. 新实践是否改变问题定义和决策结构？
6. 设计形成了何种新的人工情境？
7. 其社会责任如何被评价？

## 十二、当代延伸

“发现设计”的方法适用于：

- 平台与服务生态；
- 人工智能产品；
- 数字政府；
- 医疗服务；
- 社会创新；
- 数据可视化；
- 气候适应系统。

例如，人工智能设计不能只研究界面形式，还要发现训练数据选择、模型规则、组织治理、内容审核、用户反馈和申诉机制中的设计活动。

## 十三、批判性评估

1. 开放研究共同体的愿景强，但学科合作中的资源、职位和评价权力分析仍有限。
2. “实践判断”若缺乏明确证据标准，可能成为专家自由裁量的修辞。
3. 论文集主要依赖欧美设计研究网络，全球和地方知识仍需补充。
4. 社会责任议题提出较多，但项目实施和长期评价机制尚不充分。
5. 对服务和信息社会的判断需要结合后续平台资本主义与数据治理研究更新。

## 十四、核心命题

> 设计研究的边界不应由固定产品和职业预先封闭，而应在具体人工情境中，通过问题、知识、参与者、判断与责任被持续发现和论证。

## 十一、设计史关联：从对象史转向问题史

《Discovering Design》的历史位置，在于它把设计研究从“寻找一个统一定义”转向“观察设计如何在不同问题域中被发现”。这一转向与20世纪后半叶设计史研究对象的扩展同步：设计史不再只围绕经典产品、风格谱系与设计师传记展开，而开始研究服务、信息、组织、使用实践和制度安排。

因此，本书可以被放入以下设计史链条：

```text
工业产品与专业设计师史
→ 设计方法运动与复杂问题
→ 服务、信息和组织设计
→ 参与式设计与使用者知识
→ 平台、算法和人工智能系统
```

这条链条说明，设计对象的扩展不是简单增加材料，而是改变历史解释单位。研究者需要同时追踪问题如何被界定、哪些知识进入设计过程、谁拥有决策权，以及设计结果如何重新组织社会行动。

## 十二、研究使用与论文写作

本书适合用于论文中的三个位置：第一，在文献综述中说明设计研究为何不能被单一学科定义；第二，在方法论部分论证设计判断、跨专业协作与情境知识的重要性；第三，在设计史章节中解释从产品中心史向人工情境和社会系统史的转向。

可据此提出的研究问题包括：设计问题由谁定义；专业知识与使用者经验如何发生冲突；服务和数字系统如何改变设计史对象；开放问题是否会削弱设计责任。引用时应把“发现设计”解释为一种问题化方法，而不是把任何社会活动都无限扩张为设计。
