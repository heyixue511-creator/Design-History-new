# 0173 Guy Julier《From Visual Culture to Design Culture》增强深度报告

- 源报告：`01-book-report/0173 - Guy Julier：《From Visual Culture to Design Culture》.深度报告.md`
- 主要批次：Batch 04（工业设计与产品文化）
- 关联批次：Batch 01（设计史核心理论）、Batch 05（视觉传播）、Batch 06（数字设计）

## 一、学术定位与问题意识

《From Visual Culture to Design Culture》不是简单提出一个新术语，而是针对视觉文化研究的对象边界和解释能力进行方法论修正。视觉文化研究擅长讨论图像、观看、再现和媒介，但当代设计已经越来越多地表现为品牌系统、服务流程、空间组织、企业网络、数字界面以及非物质价值生产。若研究仍只关注“画面内部有什么”，就容易忽略图像背后的生产者、咨询机构、资本结构、技术平台、消费实践和制度环境。

Julier由此提出从“视觉文化”走向“设计文化”。这一转向不是取消视觉分析，而是把视觉分析放入更大的关系网络：设计产品如何被生产，如何进入传播和交换，如何被使用、再解释和维护，以及这些活动如何形成价值、身份与权力关系。设计文化因此同时包含物质对象、视觉表象、组织流程、专业行动和日常实践。

## 二、核心理论解析

### 1. 视觉技术变化不等于历史阶段自动替换

文章反对把油画、摄影、电视和互联网排列成彼此取代的媒介阶段。新技术出现，并不意味着旧的认知和表现方式立即消失。不同媒介、观看习惯和生产方式往往并存、重叠并相互改造。因此，设计史的分期不能只按某种视觉技术的出现来划线，而应考察技术、制度、产业、消费和文化实践如何共同重组。

这一判断修正了线性媒介史：设计史不是“印刷之后是电子、电子之后是数字”的简单序列，而是多种媒介制度长期叠合的过程。

### 2. 从画面框架转向设计关系网络

视觉文化常把分析集中于图像、符号与观看者，设计文化则要求进一步追问：

- 谁委托、组织和生产设计；
- 哪些专业知识和技术基础设施参与其中；
- 设计如何进入品牌、空间、服务和消费体系；
- 使用者如何改变设计原有意义；
- 价值如何在企业、平台、地区和社会群体之间分配。

因此，设计对象应被理解为“关系节点”，而不是孤立成品。一件产品、一个标志或一个界面都连接着生产、传播、使用和制度条件。

### 3. 设计文化连接生产研究与消费研究

Julier反对在设计史、设计研究和物质文化之间划出固定边界。设计史通常研究设计师、专业实践和制度；物质文化研究强调消费、使用和日常生活；设计文化的任务是把二者连接起来。设计既不是生产者单方面决定的意义，也不是消费者任意解释的结果，而是在生产、流通、使用和再语境化之间持续形成。

可将这一过程表示为：

```text
设计委托与专业行动
→ 生产和技术组织
→ 品牌、媒介与空间传播
→ 购买、使用和体验
→ 再解释、维护与淘汰
→ 新的设计价值与文化规范
```

### 4. 品牌只是设计文化的一种表现

文章以品牌说明当代设计文化的多维性质，但明确指出品牌不是唯一动力。品牌将产品、企业形象、服务、空间和生活方式组织为统一叙事，因而是观察设计文化的有效入口；然而，地方产业、公共机构、社会运动、专业网络和非商业实践同样会构成设计文化。

若把设计文化等同于品牌研究，就会再次把复杂社会关系压缩为市场传播。

### 5. 设计文化具有地理和制度维度

设计实践会受到城市、地区、产业集群、教育机构和政策环境影响。所谓“地方设计特色”不应仅被理解为形式风格，而要分析地方知识、生产网络、专业组织、资本流动和国际传播如何共同作用。地理位置不是静态背景，而是设计价值形成的条件。

## 三、设计史关联

本篇可以置于以下方法转向中：

```text
艺术史中的形式与作者研究
→ 视觉文化中的图像、观看与再现
→ 物质文化中的消费和日常使用
→ 设计史中的生产、专业与制度
→ 设计文化中的产品—过程—系统—价值网络
```

它与Adrian Forty、Penny Sparke、Victor Margolin和Kjetil Fallan形成互补：Forty揭示产品与社会结构；Sparke讨论现代设计、消费和身份；Margolin扩展人工世界及设计研究边界；Fallan要求理论、证据和研究尺度相互约束。Julier的独特贡献，是提供连接视觉、物质、生产和消费研究的中层分析模型。

在平面设计史中，该模型要求研究标志和版式之外的委托制度、媒体渠道、品牌治理和受众实践；在工业设计史中，需要把产品造型连接到供应链、零售空间和企业文化；在数字设计史中，界面还必须连接代码、数据、算法、平台规则和持续更新制度。

## 四、可操作研究模型

可将设计文化研究整理为五组坐标：

1. **设计产品**：物品、图像、空间、服务、界面及其组合；
2. **生产过程**：委托、研究、设计、制造、编码、维护；
3. **生产者主体**：设计师、企业、咨询机构、政府、社区和平台；
4. **消费与使用**：购买、体验、改造、分享、维修和拒绝；
5. **价值网络**：经济价值、符号价值、社会声望、地域身份和政治影响。

研究时不应只挑选一个坐标，而要说明各坐标之间的因果和中介关系。例如研究某城市品牌，应同时考察视觉系统、政策目标、咨询公司、公共空间、居民使用和旅游经济。

## 五、批判性评估与局限

第一，“设计文化”范围极广，若没有明确问题和证据边界，容易成为包罗一切的概念。第二，网络模型可能把权力冲突描述为中性的连接关系，因此必须追问谁设定标准、谁拥有资源、谁承担劳动和风险。第三，文章主要基于欧美设计研究和专业产业语境，对全球南方的非正式生产、殖民遗产和本土知识覆盖有限。第四，强调非物质价值时，不能忽略服务器、物流、材料和劳动等物质基础。

在数字平台环境中，还需补充数据采集、算法排序、内容审核、用户锁定和基础设施能源消耗。数字设计文化并非真正“非物质”，而是把物质和劳动隐藏在界面之后。

## 六、研究使用与论文写作

### 可用于《现当代设计史》的章节

- 设计史从作品与风格向生产—消费关系扩展；
- 战后品牌、企业设计和消费文化；
- 视觉文化、物质文化与设计研究的交叉；
- 全球化与地方设计产业网络；
- 数字平台与设计文化的新结构。

### 可形成的论文问题

1. 视觉文化方法为何不足以解释服务设计和平台设计？
2. 品牌如何把产品、空间和组织行为整合为设计文化？
3. 地方设计身份是如何由机构和网络生产出来的？
4. 用户使用如何改变专业设计预设的意义？
5. 数字设计文化中的价值由谁创造、占有和承担成本？

### 建议证据

- 设计提案、委托合同和企业档案；
- 品牌手册、广告、零售与空间材料；
- 行业组织、设计政策和教育资料；
- 用户访谈、使用观察和消费记录；
- 数字产品版本、平台规则和数据治理文件。

## 七、结论

Julier的核心贡献，是把设计研究从“看见什么”推进到“设计如何被生产、传播、使用并形成价值”。设计文化不是视觉文化的替代标签，而是一种跨越产品、过程、主体、消费与价值网络的关系史方法。它使设计史能够分析当代设计中难以被单件作品承载的品牌、服务、空间和数字系统。
