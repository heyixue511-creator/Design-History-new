# Penny Sparke、Fiona Fisher 编：《The Routledge Companion to Design Studies》增强报告

## 一、源报告映射与增强定位

- 源书：`00-book/Sparke, Penny; Fisher, Fiona (eds.), The Routledge Companion to Design Studies, 2016.md`
- 源报告：`01-book-report/0514 - The Routledge Companion to Design Studies（2016）.深度报告.md`
- 文献性质：设计研究综合手册 / Scholarly Companion
- 增强目标：在源报告的领域综述、全文语义地图和证据锚点基础上，把服务设计、社会设计、参与式设计、工艺、数字制造、全球化与后殖民批评整合为一套可用于研究和课程设计的分析框架。

本书所呈现的不是设计研究“是否成立”的早期辩论，而是设计研究进入成熟阶段后的内部结构：不同研究路径如何界定对象、组织参与、选择证据、判断成效，并承担社会与政治责任。

## 二、理论定位：从学科辩护到领域治理

设计研究形成期的核心问题是：设计能否成为跨学科研究对象。到了本书所代表的阶段，问题已经转变为：

```text
设计研究包含哪些路径
→ 各路径解决什么问题
→ 谁参与问题定义
→ 使用何种证据
→ 在什么尺度评价成效
→ 如何处理冲突与责任
```

因此，设计研究成熟不等于概念数量增加。服务设计、社会设计、参与式设计、批判设计、设计人类学和设计行动主义只有在能够明确对象、方法、参与者与后果时，才具有研究意义。

## 三、设计研究的五维分析矩阵

### 1. 对象维度

设计对象已从单件产品扩展为：

- 服务流程；
- 组织关系；
- 公共制度；
- 信息与交互系统；
- 开放模板和参数系统；
- 社会创新网络；
- 生产与消费生态。

对象扩展要求研究者说明边界。若研究对象被称为“系统”，必须进一步界定系统包含哪些行动者、基础设施、规则、资源与排除机制。

### 2. 参与者维度

传统专业模式把设计师置于问题定义中心。参与式与共同设计则要求区分：

```text
委托者
设计团队
服务提供者
直接使用者
受间接影响者
维护者与一线劳动者
被排除或沉默的群体
```

参与不应只指访谈或工作坊出席，而应追问不同参与者是否拥有改变目标、资源分配和最终决策的权力。

### 3. 生产维度

数字制造使工业时代的“固定模型—批量复制”范式失效。参数设计、3D打印、开源硬件和分布式制造形成新的关系：

```text
设计规则或代码
→ 可变模型
→ 地方制造
→ 独特对象或小批量结果
→ 使用反馈与再修改
```

设计史因此需要保存文件版本、软件依赖、制造参数、平台规则和修改记录，而不能只保存最终物件。

### 4. 成效维度

社会设计和服务设计的成果不能只用视觉质量或创新性评价。至少需要区分：

- 短期体验改善；
- 服务可达性；
- 组织能力变化；
- 资源和决策权重新分配；
- 长期社会与生态后果；
- 项目结束后的维护能力。

“社会创新”如果缺乏长期证据，容易把复杂结构问题改写为短期项目成功故事。

### 5. 责任维度

设计研究必须分析：

- 谁从设计中获益；
- 谁承担劳动、风险和维护成本；
- 哪些群体被专家话语替代；
- 哪些历史与殖民分类仍在延续；
- 项目失败后责任由谁承担。

## 四、工艺：从技术类别到生活世界

本书将工艺从“非工业生产方式”扩展为一种生活世界和伦理实践。工艺研究可同时关注：

1. 材料与技能；
2. 身体节奏和时间经验；
3. 师徒制与知识传递；
4. 地方经济和身份；
5. 市场与文化遗产制度；
6. 数字制作对作者、复制与独特性的重构。

这一转向避免把工艺仅作为现代工业设计的前史，也避免把工艺浪漫化为天然反工业实践。工艺同样可能受到旅游市场、国家文化政策、性别劳动和殖民分类的塑造。

## 五、社会设计：从产品替代到系统转型

社会响应设计的核心不是为弱势群体增加一种产品，而是改变问题被定义和解决的制度条件。

```text
产品方案
→ 服务流程
→ 组织合作
→ 制度与政策
→ 社会能力和长期维护
```

研究社会设计时，应区分三种层次：

- **补偿型设计**：在既有制度中改善局部体验；
- **重组型设计**：改变服务流程和组织关系；
- **转型型设计**：重新分配资源、能力和决策权。

不能因为项目使用了参与式语言，就自动判断其具有结构性效果。

## 六、专业权威与“好设计”政治

工业设计史中的“好设计”话语常同时包含三种力量：

1. 改善产品质量和公共生活的改革愿景；
2. 提升企业竞争和出口能力的市场目标；
3. 由专家决定何为正确形式和生活方式的专业权威。

Loewy、Papanek及后续社会设计理论之间并非简单进步序列。不同理论都在重新界定设计师的社会角色，但对专家权力、市场依赖和受影响者参与的处理并不相同。

## 七、全球化、殖民遗产与行动主义

设计行动不能脱离全球生产与知识分类的历史。需要同时追踪：

```text
设计决策地点
原料来源
制造地点
劳动条件
品牌与利润分配
消费地点
废弃和环境后果
```

后殖民批评进一步要求分析：谁有权将某种生产称为“工业设计”“工艺”“传统”或“发展项目”。这些分类会影响资金、档案、博物馆展示和专业可见性。

行动主义的判断标准不应只是议题立场，而应包括组织持续性、参与者权力、风险承担和实际制度变化。

## 八、与既有增强报告的理论连接

### 与 `0505 Design Studies: A Reader`

`0505` 建立设计研究的经典问题谱系；`0514` 显示这些问题在服务、社会、参与、数字制造和行动主义领域中的制度化。

### 与 `0513 An Introduction to Design and Culture`

Sparke 的设计文化框架解释生产、媒介、消费和身份如何相互构成；本书把这一框架扩展到社会创新、数字制作、服务和组织系统。

### 与 `0501 Global Design History`

全球设计史提供跨国流动与殖民权力分析；本书进一步要求当代设计行动面对供应链和后殖民知识结构。

### 与 `0510 The Politics of the Artificial`

Margolin 说明人工世界配置资源与行动能力；本书展示这种政治问题如何进入成熟设计研究的不同实践分支。

## 九、《现当代设计史》写作方法

研究一个当代设计项目时，可使用以下矩阵：

| 维度 | 核心问题 |
|---|---|
| 历史 | 该问题和专业路径如何形成？ |
| 对象 | 产品、服务、组织还是系统？ |
| 行动者 | 谁定义、制造、使用、维护并受影响？ |
| 技术 | 技术扩大了谁的能力，又限制了谁？ |
| 生产 | 设计与制造、平台和供应链如何连接？ |
| 参与 | 参与者是否拥有实际决策权？ |
| 成效 | 成果如何被长期评价和维护？ |
| 政治 | 利益、风险与可见性如何分配？ |

## 十、批判性评估

1. 设计研究领域的快速分化容易产生概念通胀，相似实践可能被不同标签重复包装。
2. 社会设计和服务设计常以项目报告代替长期社会效果证据。
3. 参与式方法可能把结构性冲突转化为工作坊中的表面共识。
4. 数字制造的开放性不自动消除平台控制、设备门槛和材料成本。
5. 国际手册仍主要依赖英语学术网络，需要地方语言研究和全球南方知识体系补充。

## 十一、当代延伸

本书的方法可以用于分析：

- 数字公共服务；
- 医疗与养老服务系统；
- 智慧城市和城市平台；
- 开源硬件与创客网络；
- 人工智能辅助设计；
- 无障碍和包容性设计；
- 气候适应与社会韧性项目。

在人工智能设计中，应特别追踪训练数据、模型提供者、平台接口、设计师判断、用户反馈、内容审核与环境成本，避免把算法当作中性工具。

## 十二、核心命题

> 设计研究的成熟，不表现为议题和专业名称的不断增加，而表现为它能否公开说明对象、参与者、证据、成效与责任之间的关系。
