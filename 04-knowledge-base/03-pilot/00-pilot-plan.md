# 第一批知识库试验计划

## 一、试验目的

第一批不追求把全部589份源报告立即批量转换，而是用具有代表性的文献校准：

- 文献与版本建模；
- 证据单元切分；
- 知识原子颗粒度；
- 人物、机构、作品和概念消歧；
- 强关系与弱关系的证据门槛；
- 学术争议和竞争解释的保存方式；
- OCR、图像缺失和资料类型误判的处理；
- 研究、写作、教学、策展、图谱和RAG的共同调用能力。

## 二、试验对象

首批选择12项，覆盖通史、设计史理论、全球史、物质文化、设计研究、UX/HCI和数字设计。

## 三、试验范围

每项文献完成：

1. 完整来源记录和版本关系；
2. 原始文件、深度报告、增强报告之间的派生关系；
3. 至少3个有代表性的章节或问题段落；
4. 至少30条可回查证据单元；
5. 至少20条单一命题知识原子；
6. 人物、机构、作品、事件、地点和概念候选实体；
7. 至少10条有证据的关系，其中强关系须人工复核；
8. 至少1项不确定性、反例或争议记录；
9. 一个跨文献比较入口。

首批总体最低目标：

| 对象 | 最低数量 |
|---|---:|
| 来源记录 | 12 |
| 版本／译本／入口关系 | 20 |
| 证据单元 | 360 |
| 知识原子 | 240 |
| 规范或候选实体 | 150 |
| 关系记录 | 120 |
| 争议或未解决问题 | 12 |
| 跨文献比较组 | 6 |

数量是最低覆盖线，不是质量替代指标。

## 四、六个比较组

### 1. 通史版本组

```text
0096 Raizman早期版本
↔ 0097 Raizman 2023版
```

重点比较章节结构、案例增删、数字设计、全球范围和责任话语，不根据年份自动推断作者立场变化。

### 2. 世界设计史卷册组

```text
0511 Volume 1
↔ 0512 Volume 2
```

检验卷册边界、连续叙事、战争断点、地域分配和全球史方法。

### 3. 设计史理论组

```text
0506 Fallan
↔ 0417 Design Discourse
```

比较设计史对象、理论来源、学科边界、方法和批评传统。

### 4. 全球物质与传播组

```text
0019 Arabic Print Revolution
↔ 0039 Empire of Cotton
```

比较印刷传播、商品链、劳动、殖民、区域网络和全球史尺度。

### 5. 设计知识与问题结构组

```text
paper 0019 Cross
↔ paper 0034 Rittel/Webber
```

区分designerly ways of knowing、设计研究身份和wicked problems的原始规划理论语境。

### 6. 数字设计与规范组

```text
0010 About Face
↔ 0040 Human-Centered AI
```

区分交互设计方法、操作规则、用户模型、规范性技术主张和AI治理判断。

## 五、执行阶段

### Phase A：来源与版本

- 建立12项来源记录；
- 核对题名、作者、年份、资料类型和具体版本；
- 连接原始文本、报告、增强报告和别名入口；
- 继承权利清单中的限制状态。

### Phase B：证据与知识原子

- 按章节、小节和论证段切分；
- 每条证据标明来源、位置、类型和支持边界；
- 将复杂概括拆成单一命题；
- 区分历史事实、作者主张、解释和模型推断。

### Phase C：实体、概念与关系

- 建立候选实体注册表；
- 规范人物、机构、作品和概念名称；
- 保存原文名称和不同译名；
- 关系先以`candidate`进入，证据充分后升级。

### Phase D：争议与跨文献比较

- 识别不同作者对同一问题的立场；
- 保存竞争解释和反例；
- 建立版本比较和概念迁移关系；
- 不把比较视图自动写成历史影响关系。

### Phase E：审计与应用测试

至少测试以下查询：

- 不同作者如何定义“现代设计”；
- Raizman不同版本对数字设计的处理有何变化；
- Margolin和Fallan对设计史对象与方法的差异；
- wicked problems从规划理论进入设计研究时发生了什么语义变化；
- 全球商品链与区域印刷传播如何形成不同的全球史尺度；
- About Face的操作规则与Human-Centered AI的规范主张如何区分。

## 六、通过条件

试验批次只有同时满足以下条件才可扩展到全库：

- JSON Schema机械校验通过；
- 证据锚点可回到原始来源；
- 随机抽查中复合命题已被合理拆分；
- 作者观点与知识库解释无系统性混淆；
- 版本和译本关系无明显误归并；
- 强关系均有证据和人工复核；
- 图像缺失和OCR风险被正确标记；
- 争议没有被自动抹平；
- 权利限制能够传递到导出记录；
- 六组比较查询可以复现其证据链。

## 七、试验后的决策

试验结束后应形成：

1. 模式修订记录；
2. 颗粒度示例集；
3. 实体消歧规则；
4. 关系误判清单；
5. 自动化可处理字段清单；
6. 必须人工复核字段清单；
7. 全库转换的批次、成本和质量方案。

在上述结果完成前，不将试验抽取规则直接推广到全部573个当前有效增强目标。
